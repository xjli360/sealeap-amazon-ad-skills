# 短生命周期打法：泳衣案例

## 适用与阶段

用于需求在单一旺季迅速上升、旺季后持续衰退、次年往往由新款接力的产品。手册泳衣案例阶段为：新品约 1-3 个月、成长约 4-15 个月、成熟/退出约 15 个月以上；这些月数是 `MANUAL_BASELINE`，必须结合实际上架日、销售斜率、天气和库存重判。

年度候选节奏：4 月预热、5 月下旬进入完整投放、6-8 月旺季、7 月下旬开始检查降档、8 月下旬进入维持或退出。每年以英国实际天气、搜索趋势和库存截止日校准。

## 消费意图与 Listing 检查

- 按塑形/舒适、大码、收腹、高腰、罩杯与胸部支撑、透明度和活动场景拆分真实意图。
- 在主图/A+ 中清楚给出 UK/EU 尺码、胸围/下胸围、臀围、躯干长度、模特尺码和面料状态。
- 只有产品确实具备时才使用 period swimwear、防晒、塑形等功能词；男性与女性意图分开建组。
- 搜索量、价格带、趋势和竞品销量必须取当前数据，不沿用手册数字。

## 新品期：低成本建立历史

手册案例预算结构（`MANUAL_BASELINE`）：

| 广告类型 | 占比 |
|---|---:|
| SP 手动精准 | 55% |
| SP 商品定向 | 15% |
| SP 自动 | 15% |
| SB/SBV | 10% |
| SD | 5% |

- 以高相关长尾和真实功能词起量，商品定向选择可解释的价格/评分/款式差异。
- 自动组负责发现词，精准组负责验证词；否定动作要保留发现路径和匹配去重逻辑。
- 同一实验周期不要同时换主图、降价、开优惠并提竞价。

## 成长期：旺季放量

手册案例预算结构（`MANUAL_BASELINE`）：

| 广告类型 | 占比 |
|---|---:|
| SP 手动 | 40% |
| SP 商品定向 | 10% |
| SP 自动 | 10% |
| SB/SBV | 25% |
| SD | 10% |
| KOC | 5% |

- 将转化稳定的 query 独立控价，按意图而非只按 match type 拆组。
- SB/SBV 展示真实覆盖、支撑、活动度和身材包容性；不要添加产品没有的 Best Seller 徽章。
- KOC 是站外变量，单独记录费用、链接和归因限制，不纳入 PPC 预算百分比的因果实验。
- 放量上限由退货后利润、尺码齐全率、补货周期和旺季剩余天数共同决定。

## 成熟/退出期：收缩并交棒

手册案例预算结构（`MANUAL_BASELINE`）：

| 广告类型 | 占比 |
|---|---:|
| SP 手动 | 35% |
| SP 商品定向 | 10% |
| SP 自动 | 5% |
| SB/SBV | 30% |
| SD | 20% |

- 优先保留利润词、品牌防守和高意向再营销，关闭无转化探索；实际窗口以账户资格为准。
- 分开判断“自然季节回落”和“Listing/价格/尺码导致的异常下滑”。
- 若老款利润与库存不再支持投放，明确退出日；把有效 query、受众洞察和创意结论交给新款，但不跨 ASIN 复制未经验证的竞价。

## 停止与回退

当季节剩余时间短于回收窗口、核心尺码缺货、退货率越过利润护栏或天气导致需求显著回落时暂停扩量。任何降档都记录原值、截止日和重启条件。

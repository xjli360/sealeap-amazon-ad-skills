# 课程案例与可用边界

## 匿名教学案例

课程用一个客单价约 25 美元、毛利率约 40%、当前 ACOS 约 35% 的珠宝成熟单品讲解诊断：

- 目标：提高成熟单品利润率；
- 整体指标示例：CPC 1.20 美元、Benchmark 0.90 美元；CTR 0.35%、Benchmark 0.50%；CVR 8%；曝光 50,000；
- 候选问题：主图、标题、价格/优惠、搜索词相关性、描述、场景图/A+、placement 和预算；
- 搜索词示例显示宽泛 `jewelry` 的 CVR 低于更具体的手链查询；
- placement 示例显示搜索顶部 ACOS 明显高于其它搜索位置和详情页；
- 课程建议是系统拆解后再优化，不应只盯 ACOS。

这只能作为诊断结构示范，不得套用其数值、关键词或创意动作。

## 源课件内部不一致

1. 优化结果表写 ACOS 从 35% 降至 22%，同页正文写降至 23%；
2. 优化后表给出 CPC 1.15、CVR 12%，若仍使用案例客单价 25 美元，按 `CPC/(CVR×AOV)` 无法回算 22% 或 23%；
3. placement 表中若以 CPC × clicks 回算 spend，多行与表内 spend 不一致；
4. 一页标题写“CPC 为什么低”，正文候选原因却是竞价过高/竞争激烈，语义应为分析 CPC 偏高；
5. Benchmark 页面一处说中位数（第 50 百分位），另一处写同业组平均 CTR/CPC，不能在没有当前字段定义时混用。

因此：

- 不把案例的 22%/23% 当作已验证结果；
- 不复制 placement 金额做计算样例；
- 所有账户诊断必须从原始 totals 重新计算；
- 当前账户结论以同口径报告和脚本复核为准。

## 可继承的方法

- 先确定策略目标；
- 重算 ACOS 与盈亏线；
- 拆成 CPC、CVR、AOV；
- 继续下钻 placement、target/search term、Listing、价格和评价；
- 用 Benchmark 找异常方向而非直接行动；
- 生成单变量实验并跟踪护栏。

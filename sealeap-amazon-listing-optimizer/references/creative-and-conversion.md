## 推导链

不要从“竞品用了什么颜色/版式”开始。按以下顺序推导：

```text
品牌定位 + 商品事实 + 目标站点证据
→ 目标购买任务与主要障碍
→ 单一创意主张（Big Idea）
→ 信息优先级
→ 文案、摄影、视频、图标和 A+ 模块
→ 移动端/桌面端 QA
→ 实验与迭代
```

Big Idea 必须能用一句话说明“谁在什么场景下，为什么应相信这个商品能解决哪一个关键问题”。它不是口号生成器，也不能超出商品证据。

同一品牌的视觉语言可以复用；每个 ASIN 的核心信息、证据、场景和规格必须独立。做到“风格一致，内容不同”。

## 创意 Brief

### 1. 项目与目标

- marketplace / ASIN / SKU / variation / 交付槽位；
- 主目标：`CTR / CVR / RETURN-REDUCTION / BRAND / EDUCATION`；
- 当前基线、问题证据和必须冻结的干扰项；
- 时间、负责人、审阅人和版本规则。

### 2. 受众与购买任务

- 基于搜索词、SQP、评论、退货、问卷或品牌研究定义需求与使用场景；
- 不凭想象补人口统计，不用敏感属性做刻板定位；
- 写明消费者已知道什么、还担心什么、购买失败会发生什么。

### 3. 商品事实与信息优先级

| 优先级 | 购买问题 | 核心信息 | 证据 ID | 允许声明 | 限制/例外 |
|---|---|---|---|---|---|

只选择 1 个一级信息、2–4 个二级信息，其余放到规格/FAQ。视觉素材不能平均强调所有卖点。

### 4. 品牌与执行规则

- 品牌语气、配色、字体、图标、摄影光线和构图原则；
- Logo 安全区、禁止样式和已授权素材；
- 目标语言、单位、日期/数字格式和本地化要求；
- 移动端最小可读要求和裁切安全区。

### 5. 单素材任务卡

每张图片或每段视频都写：

```text
slot / objective / purchase-question / one-message /
headline / support-copy / evidence-ids / composition /
must-show / may-show / must-not-show / dimensions /
mobile-crop / alt-text / owner / acceptance-criteria
```

## 信息与素材顺序

不要机械套用固定 7 图模板。按该商品最高优先的购买问题排序，常见候选如下：

| 任务 | 内容 | 适用位置 |
|---|---|---|
| 搜索识别 | 商品本体、数量/套装边界、颜色/变体 | MAIN |
| 快速确认 | 商品身份 + 一级差异 | PT01 或首个允许的创意槽位 |
| 防误购 | 尺寸、适配、兼容性、容量 | PT02/PT03 |
| 核心收益 | 使用结果 + 可证明机制/规格 | PT03/PT04 |
| 使用想象 | 真实场景、比例、人物交互 | PT04/PT05 |
| 信任证明 | 材质、细节、结构、测试/认证边界 | PT05/PT06 |
| 使用与包装 | 步骤、清洁、安装、包装内容 | PT06/PT07/视频 |
| 预期管理 | 限制、不适用情形、FAQ | PT07/A+/描述 |

主图只承担“这是什么、买到什么”的识别任务。不要把 A+ 的生活方式 Hero 误作主图，也不要用未包含道具制造套装错觉。

图片与要点应互相强化，但不要逐字重复。关键规格同时以结构化属性或可读取文本提供，不能只存在图片中。

## 文案结构

### Title

优先级：

```text
品牌 → 商品身份 → 一级真实差异 → 决策所需规格/适配 → 数量/颜色（必要时）
```

把最重要信息放在前段以适应移动端和广告截断，但不牺牲类目要求。避免华丽但模糊的措辞，例如用 “Cinema Magic” 代替真正的屏幕规格。

### Bullets

每条采用：

```text
购买结论或收益：事实/规格证明；使用边界或确认动作
```

按“身份与差异 → 尺寸/适配 → 使用与性能 → 材质/维护 → 包装与支持/限制”排序，并根据商品调整。负面评论主题若由预期差造成，应在更早位置主动回答。

### Description/A+

用于解释而非重复：

- 为什么该特性有价值；
- 如何选择尺寸/型号；
- 如何使用、安装和维护；
- 哪些人或场景不适用；
- 同品牌型号如何选择。

### Backend

只补充前台未有效覆盖的通用同义词、本地说法和合法变体。不得把可读性差的词串搬到前台文案。

## 视觉层级

以下是设计启发式，不是 Amazon 强制政策：

- 一张素材只设一个主信息，建立明确的第一、第二阅读顺序；
- 用留白、比例、对比、位置和字重建立层级，不靠堆元素；
- 优先使用易读字体；通常控制在 1–2 个字体家族，通过字重和字号变化组织信息；
- 让商品和证据成为主角，装饰元素不得竞争注意力；
- 避免小字、低对比、复杂手写体和接近边缘的关键信息；
- 在真实移动宽度下检查，而不是只看设计软件画布；
- 对比图必须使用相同口径和真实条件，不夸大比例或结果。

设计团队可借鉴竞品的信息层级和购买问题，但不得复制具体构图、图标、字体组合、照片或表达。

## A+ 与视频

按信息任务选择模块，不为填满版面而使用：

- 开场：品牌/商品一级价值主张；
- 关键收益：图片 + 简短可读取文本 + 事实证明；
- 规格/兼容：技术规格或尺寸模块；
- 使用：步骤、情景或视频；
- 选择：仅比较自有产品的比较表；
- 降低障碍：FAQ、限制和维护；
- 品牌关系：Brand Story 与产品线入口。

视频应补充静态图片难以证明的信息，例如操作、声音、组装、运动或真实比例。前几秒给出核心信息，提供字幕，并检查静音播放。

Amazon 当前公开 A+ 指南强调桌面/移动预览、文本与图片平衡、技术规格、比较、FAQ 和避免图片内嵌大量文字：

https://sell.amazon.com/blog/a-plus-content-design-guide

## AI 素材边界

- 优先用真实商品图锁定结构、颜色、比例和附件；AI 可用于概念草图、背景探索或已允许的生活方式场景。
- 不让 AI 增加商品功能、改变接口/纹理、生成未随货附件或伪造认证标志。
- 对人物、地点和使用方式做真实性、文化和安全审查；不得展示危险或不被说明书允许的使用。
- 保存输入素材权利、提示词、模型/版本、生成时间和人工修改记录。
- 逐像素检查商品本体、文字、Logo、手指、反射、阴影和透视；发现不一致则重做，不用文案掩盖。
- 主图是否允许合成/生成以当前类目政策为准；不确定时使用真实摄影。

## 交付前 QA

### 合规与事实

- [ ] 每个可验证声明都有证据 ID，且适用于对应 SKU；
- [ ] 主图、A+、视频和文案没有价格、促销、外链、二维码、竞品商标或无证据功效；
- [ ] 商品颜色、尺寸、数量、附件、包装和使用方式一致；
- [ ] 已核对素材版权、模特/场地授权和品牌规范。

### 信息与转化

- [ ] 前三项可见内容能说明“是什么、为何不同、是否适配”；
- [ ] 高频退货/差评问题被准确回答；
- [ ] 图片之间无重复任务，文字与图片互相证明；
- [ ] 有明确限制和不适用情形，未用情绪掩盖事实。

### 视觉与可访问性

- [ ] 桌面端、移动端和缩略图均检查过裁切、清晰度和阅读顺序；
- [ ] 小字、低对比和过密元素已消除；
- [ ] 关键规格有可读取文本，不只嵌在图中；
- [ ] alt text 简洁描述图片，不堆关键词。

### 交付与实验

- [ ] 文件名、尺寸、槽位、语言和版本明确；
- [ ] 每张素材有验收标准与源文件；
- [ ] Version A/B 差异足够清楚，实验变量和护栏已登记；
- [ ] 未经批准的素材没有上传或发布。

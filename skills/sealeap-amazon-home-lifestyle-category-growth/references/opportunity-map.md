# 九赛道机会图

| 赛道 | 手册研究方向 | 当前验证重点 |
|---|---|---|
| Home | 睡眠科技、可持续、空间管理 | 尺寸、材料、洗护、舒适证据、退货 |
| Home Improvement | 安全、节能、智能家装 | 安装、电气/水路、当地规范、兼容 |
| Kitchen | 智能、环保、场景化 | 食品接触、温度/涂层、清洁、安全 |
| Furniture | 收纳、多功能、智能/定制 | 承重、稳定、组装、体积重、破损 |
| Automotive | 老龄车辆、维修替换、个性化 | 年款/车型/配置 fitment、安装、道路法规 |
| Lawn & Garden | 自动化、户外生活、多功能 | 防水、供电、机械安全、天气与季节 |
| Sports | 沉浸训练、户外科技、可维修 | 人身安全、承重、穿戴适配、季节 |
| Toys | 益智、收藏、互动陪伴 | 年龄分级、小部件、材料/电池、测试 |
| Pets | 猫经济、自动喂养/清洁、陪伴 | 物种/体型、夹伤/逃逸、卫生、噪音 |

# 季节性打法：外套案例

## 适用与阶段

用于每年在相近季节回升、历史评论和品牌资产可跨年度复用的产品。手册外套案例的候选节奏为：7-8 月唤醒/准备、8 月至 9 月中下旬新品预热、9-12 月成长与旺季、1 月成熟/防守。实际阶段必须由天气、搜索趋势、库存、上架年限和销售曲线确认。

## 上线前门槛

- UK/EU 尺码、胸围/肩宽/衣长、叠穿空间和版型要清晰，先处理高频退货原因。
- 保暖、防水、防风、材质和洗护声明只能按已有证据表述。
- 主图、视频和 A+ 如实展示颜色、拉链、帽型、内衬与活动场景。
- heated gilet 等功能品若产品真实具备，单独建组并使用对应合规证据；不要与普通外套混投。
- 在促销、Black Friday 或 Boxing Day 文案上线前核验当前资格、价格历史和显示规则。

## 新品/预热期

手册案例预算结构（`MANUAL_BASELINE`）：

| 广告类型 | 占比 |
|---|---:|
| SP 手动精准 | 40% |
| SP 商品定向 | 15% |
| SP 自动 | 10% |
| SB/SBV | 30% |
| SD | 5% |

- 在旺季前完成 Listing、视频审核、库存入仓和核心 query 验证。
- 用高相关功能/版型/人群词建立词库；不要在需求尚未出现时用高竞价证明“无需求”。
- 手册的 `1.2-1.3x` 候选竞价倍数只是待验证假设，先检查利润与当前 auction 数据。

## 成长/旺季期

手册案例预算结构（`MANUAL_BASELINE`）：

| 广告类型 | 占比 |
|---|---:|
| SP 手动 | 35% |
| SP 商品定向 | 10% |
| SP 自动 | 5% |
| SB/SBV | 40% |
| SD | 10% |

- 按通勤、户外、保暖、礼赠等真实意图拆分广告与落地内容。
- Black Friday 前用户可能偏比价与收藏；Boxing Day 可能出现礼品卡、退换后补购等不同意图。分别验证，不把两段流量合并解读。
- 手册的 `1.5-1.7x` 竞价和 Boxing Day `2-3x` 日预算只能进入审批卡；必须设退货后利润、缺货和日花费停止线。
- 天气、促销、竞争对手断货和配送承诺都作为干扰项记录。

## 成熟/防守与跨年唤醒

手册案例预算结构（`MANUAL_BASELINE`）：

| 广告类型 | 占比 |
|---|---:|
| SP 手动 | 30% |
| SP 商品定向 | 10% |
| SP 自动 | 5% |
| SB/SBV | 25% |
| SD | 30% |

- 旺季末只保留利润词、品牌防守和高意向受众；把清库存与盈利增长分成不同目标。
- 再营销窗口以当前账户可用选项为准，按访问/购买时间与新品旧款分层，排除不应重复触达的人群。
- 淡季保存有效 query、创意结论、尺码退货原因和受众洞察；7-8 月再用当前趋势做唤醒测试。
- 不因“去年有效”直接恢复旧预算和竞价；先确认价格、评价、库存、竞争格局和天气。

## 停止与回退

核心尺码缺货、促销失效、配送错过节日、退货后亏损、天气异常或旺季剩余时间不足时停止扩量。回退到已记录的预算/竞价/状态，并区分季节性收缩与产品本身失速。

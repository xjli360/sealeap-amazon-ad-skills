# 商品投放场景与候选选择

## 七种应用场景

### 1. 扩大受众覆盖

关键词覆盖搜索意图，商品投放补充商品详情页、类目和关联流量。先证明新增流量是相关增量，不以曝光增加作为完成。

### 2. 突破关键词瓶颈

适用于创新商品、精准长尾需求小或核心词昂贵的情况。用相关品类/ASIN 寻找消费者已经浏览的替代入口，再以 CTR、CVR、贡献利润验证。

### 3. 类目节点流量

适用于消费者常按类目浏览的商品。课程举例时尚、服装、礼品。必须确认当前节点、商品归属和细化条件，不能投宽泛类目后依靠否定补救。

### 4. 细分目标人群

当关键词无法区分价格带、功能或场景时，用品类细化或具体 ASIN 近似筛选购买任务。不要从商品推断敏感人群属性。

### 5. 交叉销售与升级销售

定向互补商品或自家升级款。需要证明商品确实能搭配、兼容或形成升级，不制造套装/兼容误解。

### 6. 自家流量防御

用自家相关商品覆盖详情页、形成产品矩阵。防御应看净销售、品牌内替代和利润，而不是只看被点击商品的 ACOS。

### 7. 竞品流量进攻

定向同需求且可竞争的商品。比较商品事实、价格、配送、评分、评价量、优惠、变体和页面承接。不得作无证据对比或使用竞品商标文案。

## 3WCS 候选框架

课程将以下框架标为第三方卖家意见：

| 维度 | 问题 | 必须证据 |
|---|---|---|
| What | 是什么、功能/特性/材质/尺寸/售卖方式 | 商品事实 |
| Who | 谁在完成什么购买任务 | 查询、评论、购买或研究证据 |
| Where | 在什么场景使用 | 商品事实与行为证据 |
| Competitor | 谁满足相同任务 | 当前商品页与市场观察 |
| Substitute | 谁是替代或互补商品 | 购买任务、兼容/搭配证据 |

不要把框架名称当作官方方法，不要凭空生成人群画像。

## 候选分级

课程的榜单分级建议可改造成证据分级：

### TIER_1_TESTABLE

- 商品与购买任务高度相关；
- 有账户出单、高质量点击或可复核市场证据；
- 价格/配送/评价/功能存在可竞争点；
- 有利润上限和明确停止规则。

### TIER_2_EXPLORE

- 相关性合理，但缺账户样本；
- 只用小预算、独立 ad group；
- 不与 TIER_1 共享预算。

### EXCLUDE

- 不相关或购买任务冲突；
- 明显无流量、不可竞争或合规风险；
- 账户证据显示长期低质量且样本充分；
- 无法证明兼容、搭配或商品事实。

“Top ASIN”“新品 ASIN”“长尾 ASIN”本身都不是投放理由。

## 排名字段建议

| 字段 | 说明 |
|---|---|
| relevance | 与商品身份、购买任务、场景的一致性 |
| relationship | competitor / substitute / complement / own-defense / upsell |
| traffic_evidence | 账户报告、榜单或前台观察及日期 |
| competitiveness | 价格、配送、评分、评价、功能、优惠差异 |
| account_signal | impressions/clicks/orders/sales/profit 与窗口 |
| economics | 可承受 CPC、贡献利润和预算上限 |
| risk | 商标、兼容、声明、库存或样本风险 |
| freshness | 数据与前台检查时间 |

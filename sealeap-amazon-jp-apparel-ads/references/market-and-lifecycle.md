# 日本站市场、消费者与生命周期

## 全年运营节奏

手册将日本站服饰节奏概括为“淡季建基础，旺季收成果”：

| 时间 | 手册观察 | 可验证的运营假设 |
|---|---|---|
| 1-2月 | 节后低谷 | 低成本测试、优化 Listing、累积评论与搜索词数据 |
| 3-4月 | 入学/入职与樱花季 | 为背包等场景品类提前入仓并切换创意 |
| 4-5月 | 新品黄金入场窗口 | 为夏季或 Q4 拉长评论、Listing 和广告数据积累期 |
| 6月 | 夏季奖金、梅雨季 | 验证防水、轻薄、透气等真实需求 |
| 7-8月 | Prime 会员日、盛夏和出行 | 夏季品放量，同时检查库存与退货风险 |
| 9-10月 | Q4 备货和预热 | 完成评论、关键词和品牌素材的准备 |
| 11-12月 | 黑五、圣诞和年末 | 在利润与库存护栏内集中投入 |

不要把整个服饰大类的季节曲线直接用于单个细分品类。用当前细分品类与 ASIN 数据确认峰值是否一致。

## 日本消费者信号

手册中的调研信号可用来构造验证问题：

- 价格与优惠：使用优惠券、在线调研和比价的比例较高。检查搜索结果中价格、积分和配送信息是否清晰。
- 品牌信任：手册强调“可靠、真实、帮助简化生活”。把功能、尺寸、材质和使用边界如实呈现，不用空泛高端词替代证据。
- 积分：手册把 Amazon Points 视为重要决策信号。执行前读取当前积分设置与活动资格，不假设默认值始终不变。
- 复购：手册将首次购买后前3个月视为重要观察期。先用当前品类购买间隔验证，再设置展示型推广窗口。
- 跨品类：家居、健康个护和美妆被手册列为高交叉品类。只在产品具有合理配套场景时做交叉营销，不因统计相关性强行绑定。

## 四大挑战与诊断问题

| 挑战 | 诊断问题 |
|---|---|
| 消费习惯差异 | 产品是否从“款式”之外说清日本买家重视的功能、做工和生活简化价值？ |
| 季节容错低 | 评论、排名、素材、入仓和预算是否在需求爬坡前到位？ |
| Listing/品牌门槛 | 点击后不转化是否来自尺码、功能、材质、图文不一致或评论门槛？ |
| 生命周期打法错配 | 是否在低客单功能品新品期过早重投品牌，或在高信任门槛品中只投 SP？ |

## 阶段判定

1. 先计算上架时间、当前销售相对峰值和增长率。
2. 再识别周期性：每年回升不等于新品重启，可能是季节性。
3. 检查评论、自然位、品牌词和广告销售占比，确认是否已建立自然流量。
4. 把库存剩余天数和补货周期纳入阶段判定：无法支撑旺季的库存不应触发放量。
5. 对无法归类的产品输出 `UNCERTAIN_LIFECYCLE`，要求更长销售曲线或细分品类趋势，不强行套用案例。

# Weixin Amazon Skills

本目录收录 50 个由最近一年公开高阅读或高互动 Amazon 运营内容转译而来的独立 Skill，共 5 个匿名集合、每个集合 10 个 Skill。

## 使用边界

- 集合名采用未与现有目录重复的中国神兽代号，只用于匿名分组。
- 公开 Skill 不保存或暴露素材来源身份、账号、链接、文章编号、发布日期、阅读量或原始话术。
- 文章观点只作为待验证启发；Amazon 当前官方规则、一方业务报告和账户实时状态优先。
- 所有输出区分 `FACT`、`ESTIMATE`、`ASSUMPTION` 与 `UNKNOWN`。
- 默认提供诊断和草案；外部写入前展示具体变更、影响与回退，并核对已有授权是否覆盖对象、动作与预算。已授权范围继续执行并回读核验，新增范围另行请求批准。
- 来源映射、筛选口径和语义草稿只保存在仓库已忽略的私有素材目录。

# Amazon 变体主题迁移执行手册

## 执行台账

| 阶段 | 核心动作 | 最低留痕 |
|---:|---|---|
| 1 | 冻结当前父子关系、主题、属性、SKU/ASIN、库存与前台展示快照。 | 记录输入、证据状态、负责人和下一检查点 |
| 2 | 下载目标站点当前模板，把主题分为仍有效、已弃用、未知三类，并保存证据日期。 | 记录输入、证据状态、负责人和下一检查点 |
| 3 | 区分无需更新且仍正常的家族，与必须改动或已报错的家族；未知项保持 HOLD。 | 记录输入、证据状态、负责人和下一检查点 |
| 4 | 把每个子体映射到一个真实且当前有效的差异维度，生成旧值、新值和不可迁移项。 | 记录输入、证据状态、负责人和下一检查点 |
| 5 | 先在低风险家族或最小批次执行草案，核对父子关系、可售状态、详情页与搜索后再继续。 | 记录输入、证据状态、负责人和下一检查点 |
| 6 | 若出现子体孤立、属性丢失、库存异常或页面错误，立即停止；仅恢复仍符合当前主题规则的已知有效映射，弃用主题不能盲目回填，无法安全恢复时升级人工支持。 | 记录输入、证据状态、负责人和下一检查点 |

## 证据台账字段

- `claim`：要支持或反驳的判断。
- `status`：`FACT / ESTIMATE / ASSUMPTION / UNKNOWN`。
- `source_type`：Amazon 一方、账户一方、用户输入、第三方代理或公开观察。
- `marketplace / object / window / sample`：站点、对象、窗口和样本。
- `value / unit / definition`：数值、单位和字段定义。
- `limitations`：缺失、延迟、归因、选择偏差和可能的反向解释。
- `decision / owner / next_check`：决定、责任人和复核时间。

## 关键检查

- 模板和帮助页是目标站点的当前版本
- 父子体只因真实购买差异形成关系
- 每一批都有更新前快照和回退值
- 更新后同时验证后台与前台

## 动作变更表

| 对象 | 旧值 | 新值 | 依据 | 预期 | 停止条件 | 回退值 | 审批 |
|---|---|---|---|---|---|---|---|
| 待填写 | 待读取 | 草案 | 证据编号 | 待验证 | 预先定义 | 原值 | 未批准 |

没有明确批准时，审批列保持“未批准”，不得把草案写成已执行。

## 决策门

- `READY`：一方事实、适用规则和对象均已对齐；单位经济可接受；动作可回退。
- `HOLD`：仍缺关键字段、样本或专业复核；只列补证路径。
- `STOP`：确认违规、证据虚假、客户权益受损、成本越界或回退不可行。

## 质量检查

- 所有表格使用同一站点、币种、时区、父子体和统计窗口。
- 平台总体数据、第三方估算、个案和相关性没有写成自身确定结果。
- 成功指标与反证、干扰变量、样本限制同时呈现。
- 当前功能或政策的检查日期明确，旧截图不冒充当前事实。

## 交付模板

1. 任务、站点、对象和时间窗
2. 证据台账与数据口径
3. 诊断或假设
4. 方案、情景与单变量实验
5. 风险、停止线和回退
6. `READY / HOLD / STOP`
7. 下一步、负责人和待批准动作

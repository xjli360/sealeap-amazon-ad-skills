# Amazon 新品推广就绪门

## 目标

把新品推广拆成产品、合规、报价、内容、库存、流量和度量七个就绪门；广告只在页面和商业模型能承接时启动。

## 何时使用

- 新品准备开广告但其他条件尚不明确
- 需要判断何时试投、何时暂停或补证
- 推广费用高却无法区分产品、页面和流量问题

## 开始前要拿到

- 站点、ASIN、产品任务、差异证据和合规状态
- 价格、优惠、配送、页面、图片、A+ 与当前前台 QA
- 库存、补货、单位经济、退货和售后能力
- 关键词/ASIN 候选、预算、归因、学习目标与停止线

缺失项必须标为 `UNKNOWN` 或 `NEEDS_EVIDENCE`；不得猜数字、补属性，或混用不同站点、ASIN、流量来源和时间窗。

## 不可妥协的边界

- 当前 Amazon 官方规则、目标账户实时状态、真实产品证据和一方业务报告优先；公开内容与第三方数据只能作为待验证启发。
- 默认提供诊断或草案。写入前展示对象、旧值、新值、影响、停止线与回退，核对用户已有授权是否覆盖对象、动作与预算；范围已明确授权时继续执行并回读核验，只有未覆盖或扩大的范围才请求批准。
- 数值、政策、因果和执行状态分别标为 `FACT`、`ESTIMATE`、`ASSUMPTION` 或 `UNKNOWN`。
- 不保存或输出素材来源身份、账号、链接、文章编号、发布日期、阅读量、原始话术、图片或其他可反查线索。
- 不复制他人文案、图片或品牌表达；输出必须基于当前商品重新设计。
- 开广告不是完成新品推广；任一硬门失败时不得用付费流量掩盖。
- 不得用刷单、激励评价、虚假折扣或操纵变体制造冷启动。
- 销售和排名结果不可保证，所有学习预算受毛利和库存约束。

## 工作流

1. 通过产品任务、差异、合规和知识产权硬门，缺项先 HOLD。
2. 核对价格、配送、库存、Featured Offer 条件和页面移动端体验。
3. 重算含广告、退货和补货风险的单位经济及最大试验损失。
4. 把新品假设拆成需求、点击、转化和复购/退货四类可观测问题。
5. 分别设置发现、精准验证和产品定向的小预算结构，不一次铺满。
6. 按预设样本复盘第一个失效环节，修复一个变量后再继续或退出。

## 判断状态

- `READY`：产品事实、规则、基线和测试方法均已核实。
- `HOLD`：方向可能成立，但买家证据、产品证明、样本或审批仍缺失。
- `STOP`：内容误导、侵权、违规、单位经济不可承受或无法回退。

## 必须交付的结果

- 七项新品就绪评分卡
- 最大试验损失与库存边界
- 发现/验证广告草案
- 阶段结果、停止和退出记录
- 数据范围、采集时间、证据状态、限制和待批准动作

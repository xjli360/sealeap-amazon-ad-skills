# Amazon 自然排名后广告递减

## 目标

确认关键词自然表现稳定后，小步降低同词付费强度，同时观察总点击、订单、搜索份额、利润和自然位置，必要时立即恢复。

## 何时使用

- 关键词自然排名进入首页后考虑降广告
- 担心广告蚕食自然订单或停广告后掉量
- 需要用查询级实验释放预算

## 开始前要拿到

- 站点、ASIN、关键词/搜索词、自然与广告位置采样
- 同窗口的曝光、点击、订单、广告销售、总销售与搜索份额
- 竞价、位置加价、预算、CPC、CVR、贡献毛利和库存
- 价格、促销、评价、竞品、季节和页面变更记录

缺失项必须标为 `UNKNOWN` 或 `NEEDS_EVIDENCE`；不得猜数字、补属性，或混用不同站点、ASIN、流量来源和时间窗。

## 不可妥协的边界

- 当前 Amazon 官方规则、目标账户实时状态、真实产品证据和一方业务报告优先；公开内容与第三方数据只能作为待验证启发。
- 默认提供诊断或草案。写入前展示对象、旧值、新值、影响、停止线与回退，核对用户已有授权是否覆盖对象、动作与预算；范围已明确授权时继续执行并回读核验，只有未覆盖或扩大的范围才请求批准。
- 数值、政策、因果和执行状态分别标为 `FACT`、`ESTIMATE`、`ASSUMPTION` 或 `UNKNOWN`。
- 不保存或输出素材来源身份、账号、链接、文章编号、发布日期、阅读量、原始话术、图片或其他可反查线索。
- 不复制他人文案、图片或品牌表达；输出必须基于当前商品重新设计。
- 自然排名与广告可能共同受销量、价格、季节和竞争影响，不能用相关性证明蚕食或带动。
- 不得一次停掉全部活动；每次只改变该查询的一个主要付费变量。
- 首页不是统一稳定状态，必须定义位置、设备、邮编、时间和持续窗口。

## 工作流

1. 固定采样条件，证明目标查询的自然可见度在多个周期内稳定。
2. 建立该查询的自然、付费、总点击、总订单、利润和搜索份额基线。
3. 检查同词在不同活动、匹配类型和位置的重叠，明确要减的单一变量。
4. 按小步幅递减竞价或预算，其他价格、促销、页面和库存保持不变。
5. 观察预设窗口内总业务而非只看 ACoS，并记录竞争和季节干扰。
6. 触发总订单、利润、位置或库存停止线时恢复；稳定则决定保留或继续小步测试。

## 判断状态

- `READY`：产品事实、规则、基线和测试方法均已核实。
- `HOLD`：方向可能成立，但买家证据、产品证明、样本或审批仍缺失。
- `STOP`：内容误导、侵权、违规、单位经济不可承受或无法回退。

## 必须交付的结果

- 查询级自然/付费基线
- 重叠与边际贡献分析
- 递减阶梯和回退值
- 总业务结果及不可归因项
- 数据范围、采集时间、证据状态、限制和待批准动作

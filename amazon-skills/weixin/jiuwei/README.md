# 九尾：视觉表达与实验

本集合包含 10 个独立、可复用的 Amazon 工作流 Skill。`jiuwei` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-jiuwei-amazon-content-native-listing-test` | 将对话、场景和人物视角转译为清楚的电商信息结构，以真实买家问题和产品事实做单变量创意测试。 |
| `sealeap-jiuwei-amazon-buyer-question-image-brief` | 用一张附图回答一个高频购买疑问，让顾客快速理解产品是否适用，同时保留证据、限制条件和合规边界。 |
| `sealeap-jiuwei-amazon-main-image-distinctiveness-test` | 在主图政策和类目识别不变的前提下，用一个可解释的视觉变量测试点击差异，不声称能操纵视觉推荐池。 |
| `sealeap-jiuwei-amazon-human-centered-product-brief` | 从买家行为、任务和替代方案形成产品简报，让功能与情绪结果都可验证。 |
| `sealeap-jiuwei-amazon-perceived-value-copy-brief` | 将真实事实连接到优势、客户结果和证明，用受约束的感知表达降低理解成本。 |
| `sealeap-jiuwei-amazon-new-product-launch-readiness` | 以产品、合规、报价、页面、库存、经济和广告七项门判断新品是否可试投。 |
| `sealeap-jiuwei-amazon-organic-rank-ad-taper` | 自然位置稳定后小步递减同词广告，用总业务和利润判断边际价值并随时回退。 |
| `sealeap-jiuwei-amazon-low-conversion-diagnosis` | 沿流量、位置、报价、页面、评价、产品与市场排查有点击低转化的首个失效环节。 |
| `sealeap-jiuwei-amazon-creative-kpi-scorecard` | 将设计可控质量与团队共同承担的 CTR、CVR 和业务结果分开评价。 |
| `sealeap-jiuwei-amazon-image-composition-test` | 让一张图只回答一个购买问题，保证真实比例和移动可读，并做单变量构图测试。 |

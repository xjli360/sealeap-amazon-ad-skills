# Amazon 有点击低转化诊断

## 目标

沿曝光—点击—页面—报价—购买路径找到第一个失效环节，区分流量错配、承接问题和市场变化，再只修一个主要变量。

## 何时使用

- 广告有曝光和点击但订单少或转化下降
- 不知道该先改关键词、价格、评价、图片还是产品
- 频繁同时调广告和 Listing 却无法归因

## 开始前要拿到

- 站点、ASIN、活动、位置、target 与实际搜索词/匹配 ASIN
- 同窗口曝光、点击、花费、订单、CVR、退货和总业务基线
- 价格、优惠、配送、库存、评价变化、页面版本和变体状态
- 竞品促销、需求趋势、季节和异常事件

缺失项必须标为 `UNKNOWN` 或 `NEEDS_EVIDENCE`；不得猜数字、补属性，或混用不同站点、ASIN、流量来源和时间窗。

## 不可妥协的边界

- 当前 Amazon 官方规则、目标账户实时状态、真实产品证据和一方业务报告优先；公开内容与第三方数据只能作为待验证启发。
- 默认提供诊断或草案。写入前展示对象、旧值、新值、影响、停止线与回退，核对用户已有授权是否覆盖对象、动作与预算；范围已明确授权时继续执行并回读核验，只有未覆盖或扩大的范围才请求批准。
- 数值、政策、因果和执行状态分别标为 `FACT`、`ESTIMATE`、`ASSUMPTION` 或 `UNKNOWN`。
- 不保存或输出素材来源身份、账号、链接、文章编号、发布日期、阅读量、原始话术、图片或其他可反查线索。
- 不复制他人文案、图片或品牌表达；输出必须基于当前商品重新设计。
- 少量点击不足以证明低转化；必须给出样本、窗口和预期购买周期。
- 评价只能作为诊断信号，不得操纵、干预或选择性隐藏。
- 不得同时改关键词、价格、主图和页面内容来追求即时回升。

## 工作流

1. 先核对报表口径、归因延迟、异常点击和统计样本是否足够。
2. 从实际搜索词/ASIN 与位置判断流量是否与产品和目标一致。
3. 检查价格、优惠、配送、库存、Featured Offer 和变体可买性。
4. 对比广告形成的预期与主图、标题、要点、图片、A+ 和评价证据。
5. 检查竞品、需求、季节和新负面反馈等外部变化，区分时间相关与因果。
6. 按影响和可控性选择一个根因试验，设成功、停止和回退后复测。

## 判断状态

- `READY`：产品事实、规则、基线和测试方法均已核实。
- `HOLD`：方向可能成立，但买家证据、产品证明、样本或审批仍缺失。
- `STOP`：内容误导、侵权、违规、单位经济不可承受或无法回退。

## 必须交付的结果

- 漏斗与样本质量检查
- 流量/报价/页面/市场根因树
- 优先级和单变量修复
- 复测、反证与回退记录
- 数据范围、采集时间、证据状态、限制和待批准动作

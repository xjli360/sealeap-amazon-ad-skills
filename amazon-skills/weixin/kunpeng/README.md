# 鲲鹏：AI 购物与内容

本集合包含 10 个独立、可复用的 Amazon 工作流 Skill。`kunpeng` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-kunpeng-amazon-image-compliance-audit` | 从当前官方规则、类目覆盖规则和后台错误证据出发定位图片问题，避免把未经证实的“新规”或流量传言当作根因。 |
| `sealeap-kunpeng-amazon-ai-shopping-visibility-diagnosis` | 区分季节、价格、库存、广告、索引、竞争和 AI 购物入口等可能原因，用可复核测试判断页面信息缺口，不把流量波动单因归因给 AI。 |
| `sealeap-kunpeng-amazon-ai-readable-listing-brief` | 把真实产品证据组织成清晰、可扫描、可比较的购买信息，同时保持关键词相关性和政策合规，不追逐未经验证的生成式排名公式。 |
| `sealeap-kunpeng-amazon-price-alert-demand-plan` | 把目标价提醒需求视为未知情景，以价格弹性、毛利和库存约束受控试验。 |
| `sealeap-kunpeng-amazon-tax-data-reconciliation` | 按主体、账号、期间和币种勾稽平台涉税报告、订单、支付与账簿，并交专业人士复核。 |
| `sealeap-kunpeng-amazon-environmental-claim-evidence` | 将环保声明逐项连接到 SKU、材料、证书范围和有效期，无法证明则删除或 HOLD。 |
| `sealeap-kunpeng-amazon-ai-answer-coverage-test` | 用中立问题采样 AI 购物答案，核对事实覆盖并做合规单变量页面修复。 |
| `sealeap-kunpeng-amazon-search-discoverability-triage` | 分开状态、抑制、索引、报价资格、查询相关性和排名，定位商品搜不到的根因。 |
| `sealeap-kunpeng-amazon-ai-keyword-research-control` | 让 AI 做关键词分类去重，人工控制产品相关、商标和合规，并以一方数据验证。 |
| `sealeap-kunpeng-amazon-ai-tool-evaluation` | 用同一脱敏测试集比较人工与工具的准确、成本、隐私、权限和可退出性。 |

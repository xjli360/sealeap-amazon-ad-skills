# 螣蛇：广告诊断与恢复

本集合包含 10 个独立、可复用的 Amazon 工作流 Skill。`tengshe` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-tengshe-amazon-sp-ad-framework-audit` | 把 SP 广告拆成发现、验证、防守和扩量任务，使每个活动有独立预算、证据和停止规则，并先解决页面与商业模型问题。 |
| `sealeap-tengshe-amazon-paid-organic-recovery` | 用时间线和分词证据找出自然流量下降的可控原因，分阶段调整预算，避免因一次性砍掉有效广告造成销量和学习数据二次受损。 |
| `sealeap-tengshe-amazon-head-keyword-readiness` | 把“要不要打大词”变成可审计的阶段判断，以单量缺口、经济性和库存计算试点上限，而不是用搜索量或个案决定。 |
| `sealeap-tengshe-amazon-brand-story-module-plan` | 核对 Brand Story 与当前替代模块，按品牌事实、目录导航和移动体验设计卡片。 |
| `sealeap-tengshe-amazon-ai-summary-consistency-audit` | 采样 AI 商品摘要/音频，逐条回溯产品证据并修复权威页面字段。 |
| `sealeap-tengshe-amazon-amc-query-review` | 审查 AMC 查询的事件粒度、JOIN、去重、窗口、隐私阈值和已知总量。 |
| `sealeap-tengshe-amazon-search-term-migration` | 将有重复经济证据的客户查询迁入精准结构，并在否定来源前检查重叠。 |
| `sealeap-tengshe-amazon-portfolio-budget-triage` | 将商品分成保护、证明、修复、收割和退出组，集中有限学习预算。 |
| `sealeap-tengshe-amazon-market-operability-gate` | 超越蓝海标签，用购买理由、信任、竞争响应、经济和团队能力判断进入。 |
| `sealeap-tengshe-amazon-weekly-operating-cadence` | 用风险红线、例外巡检、周度复盘和负责人闭环替代反应式忙碌。 |

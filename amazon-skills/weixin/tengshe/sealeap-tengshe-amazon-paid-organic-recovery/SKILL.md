# Amazon 付费与自然流量恢复

## 目标

用时间线和分词证据找出自然流量下降的可控原因，分阶段调整预算，避免因一次性砍掉有效广告造成销量和学习数据二次受损。

## 适用任务

- 做当前状态的只读诊断。
- 形成有证据、可审批、可回退的计划或单变量实验。
- 判断信息不足时应继续验证、暂停还是保持 `HOLD`。

## 开始前要拿到

- 同口径业务报告、广告报告、搜索查询表现和关键词自然位。
- 价格、库存、促销、评价、Listing、竞品和广告变更时间线。
- 分广告类型净贡献、TACoS、目标词份额和预算约束。

缺少字段时明确标为 `UNKNOWN` 或 `NEEDS_EVIDENCE`，不要补造数据。

## 不可妥协的边界

- Amazon 当前官方规则、账户实时状态和一方业务报告优先；公开内容与第三方数据只能作为待验证启发或代理证据。
- 数值、政策、因果与执行状态分别标为 `FACT`、`ESTIMATE`、`ASSUMPTION` 或 `UNKNOWN`。
- 不捏造销量、搜索量、成本、产品属性、合规状态、评论、广告结果或平台机制。
- 默认提供诊断或草案。写入前展示对象、旧值、新值、影响、停止线与回退，核对用户已有授权是否覆盖对象、动作与预算；范围已明确授权时继续执行并回读核验，只有未覆盖或扩大的范围才请求批准。
- 不保存或输出素材来源身份、账号、链接、文章编号、发布日期、阅读量、原始话术或其他可反查线索。
- 平台界面、功能、费率、资格和规则会变化；执行前必须在目标站点复核。

## 工作流

1. 确认“自然占比下降”来自自然量下降、广告量上升还是两者同时变化。
2. 按关键词和日期对齐价格、库存、页面、促销、竞争及各广告类型变更。
3. 建立多个根因假设，不把广告类型与自然排名关系先验写死。
4. 选择少量核心词和承接良好的 ASIN，设计逐步预算重配或 SP 恢复试验。
5. 设置销量、净贡献、自然位、库存和学习期护栏，避免一次性大改。
6. 按周评估绝对自然订单、总净贡献与目标词表现；无改善则回退并重查根因。

## 判断规则

- 广告/自然占比是构成指标，必须同时报告绝对会话和订单。
- SB、Display 或 SP 与自然排名的因果关系若无受控证据，只能标为假设。
- 恢复自然流量不应以无限亏损、断货风险或虚假促销为代价。

## 必须交付的结果

- 付费/自然分解
- 根因时间线与假设树
- 分阶段恢复方案
- 护栏、回退与结论置信度

结尾列出站点、数据窗口、口径、证据、关键假设、缺口、风险、下一步和所有待批准动作。证据不足时写 `HOLD`，不得包装成可直接执行。

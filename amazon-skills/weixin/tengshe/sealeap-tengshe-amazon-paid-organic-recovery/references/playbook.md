# Amazon 付费与自然流量恢复执行手册

## 工作表

| 阶段 | 必须记录 | 通过条件 |
|---|---|---|
| 分解 | 自然/广告会话、订单、份额和绝对量 | 识别分母变化而非只看占比 |
| 时间线 | 价格、库存、页面、促销、评价、竞品和广告变更 | 每个假设绑定可观测证据 |
| 试验 | ASIN、词、预算重配、阶段、护栏和回退 | 渐进调整，不一次性切断有效流量 |
| 复盘 | 绝对自然量、目标词、总净贡献、TACoS 和库存 | 相关与因果分开 |

## 证据台账字段

- `claim`：当前要支持或反驳的判断。
- `status`：`FACT`、`ESTIMATE`、`ASSUMPTION` 或 `UNKNOWN`。
- `source_type`：Amazon 一方、账户一方、第三方代理、公开观察或用户输入。
- `marketplace/window/sample`：站点、时间窗和样本量。
- `value/unit/definition`：数值、单位和字段定义。
- `limitations`：缺失、延迟、归因、选择偏差和可能的反向解释。
- `decision/owner/next_check`：当前决定、责任人和复核点。

## 指标与计算

- 自然占比 = 自然订单 / 总订单，同时报告分子分母。
- 按关键词跟踪自然位、SP 曝光点击订单和同期外部干扰。
- 整体成功以净贡献和可持续订单判断，不以低 ACoS 单独判断。

公式必须展示输入、单位和窗口；任何经验阈值都标为团队可调参数，并给出悲观、基准和乐观情景。

## 状态门

- `READY`：关键输入完整，政策和账户资格已核实，实验有预算、停止线和回退。
- `HOLD`：方向可能成立，但一个或多个关键证据仍缺失。
- `STOP`：出现硬性违规、不可承受经济性或无法回退的风险。

立即 `STOP` 的典型条件：

- 没有调整前基线或变更日志。
- 方案依赖未经证实的广告类型排名因果。
- 销量、利润或库存触发预设护栏。

## 质量检查

- 当前规则与账户状态的检查日期明确；旧截图和旧经验不能冒充当前事实。
- 所有表格使用相同站点、货币、时区、父子体、归因和统计窗口。
- 没有把平台总体数据、第三方估算、个案或相关性写成自身确定结果。
- 草案与实际写入分开；实际变更前展示对象、旧值、新值、影响和回退，确认已有授权覆盖后执行并回读核验；新增范围才另行请求批准。
- 复盘同时呈现成功指标、反证、干扰变量和样本限制。

## 交付模板

1. 任务、站点、对象与时间窗
2. 证据台账与数据口径
3. 诊断或假设
4. 方案/实验及敏感性情景
5. 风险、停止线和回退
6. `READY`、`HOLD` 或 `STOP` 结论
7. 下一步、负责人和待批准动作

## 自然与增量证据口径

只把报告明确区分的自然指标称为实测自然量。总订单与广告归因订单在日期、窗口、购买 ASIN 或去重范围不一致时，不能相减得到自然订单；可比但不完全可识别的差额仍标为代理值。没有查询级数据时使用可观测的 ASIN 总量与重复排名采样，不补造自然词级订单。前后变化需要记录价格、季节、库存和竞争干扰，不能直接当作广告增量。

## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。
- `ACoS = 广告花费 / 归因销售额`；`TACoS = 广告花费 / 同范围总销售额`，两者不能互换。保本 ACoS 的分母也使用同口径归因销售额，净收入、含税收入与扣退货收入不得混用。

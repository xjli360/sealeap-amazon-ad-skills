# Amazon 搜索词精准迁移执行手册

## 执行台账

| 阶段 | 核心动作 | 最低留痕 |
|---:|---|---|
| 1 | 对齐 targeting 和 search term 报告的站点、窗口、归因和对象。 | 证据、口径、负责人和下一检查点 |
| 2 | 把 target 与实际查询分栏，清理拼写、变体、品牌和不相关意图。 | 证据、口径、负责人和下一检查点 |
| 3 | 按相关性、重复订单、CVR、CPC、利润和样本质量筛选迁移候选。 | 证据、口径、负责人和下一检查点 |
| 4 | 为候选建立精准广告单元，按经济性定价；SP 需要独立预算时拆分 campaign，先保留原发现来源用于比较。 | 证据、口径、负责人和下一检查点 |
| 5 | 检查现有精准覆盖与内部竞争；仅在有证据时对原来源加否定。 | 证据、口径、负责人和下一检查点 |
| 6 | 观察总查询表现、发现量和净贡献，决定保留、调价、回退或继续发现。 | 证据、口径、负责人和下一检查点 |

## 证据台账

- 记录站点、对象、时间窗、数据定义、来源类型和采集时间。
- 区分平台/账户事实、第三方估算、分析假设与未知项。
- 广告数据写明归因窗口、target、实际搜索词/ASIN、placement 和同期变化。
- SQL 或自动化输出保留版本、参数、行数、检查总量和错误信息。

## 关键检查

- 两个报告窗口与归因一致
- 候选不是偶然单或低相关词
- 竞价有利润上限
- 否定不会切断有价值发现

## 决策门

- `READY`：证据与对象对齐，当前功能/规则确认，动作可解释可回退。
- `HOLD`：缺一方数据、正确粒度、账户资格、样本或责任人。
- `STOP`：违规、隐私泄露、连接/归因错误、预算越界或不可逆风险。

## 交付模板

1. 任务、站点、对象和时间窗
2. 证据与数据口径
3. 诊断、查询或结构草案
4. 实验/行动与资源边界
5. 风险、停止和回退
6. `READY / HOLD / STOP`
7. 负责人、下一检查和待批准动作


## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。
- `广告订单 CVR = 同口径归因订单 / 广告点击`，计算时用小数（10% = 0.10）。每访客购买率、件数转化率与订单 CVR 不可互换；`CPA = CPC / 订单 CVR` 的比较基准是每单广告前贡献，含多件订单时按订单汇总。

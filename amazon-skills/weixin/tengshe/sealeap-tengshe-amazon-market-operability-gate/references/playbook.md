# Amazon 市场可运营性门执行手册

## 执行台账

| 阶段 | 核心动作 | 最低留痕 |
|---:|---|---|
| 1 | 从具体购买任务、使用者、场景和价格带定义可比市场。 | 证据、口径、负责人和下一检查点 |
| 2 | 验证需求规模、趋势、季节和替代方案，并记录第三方证据边界。 | 证据、口径、负责人和下一检查点 |
| 3 | 写出本品为何值得买、如何证明、需要跨越的评价/品牌/内容信任门槛。 | 证据、口径、负责人和下一检查点 |
| 4 | 模拟竞品降价、复制、广告加剧和供应波动，测试差异的可防守性。 | 证据、口径、负责人和下一检查点 |
| 5 | 重算 landed cost、广告、退货、库存和现金周期，并核对团队执行缺口。 | 证据、口径、负责人和下一检查点 |
| 6 | 按进入、有限验证、等待或退出给结论，关键证据缺失时保持 HOLD。 | 证据、口径、负责人和下一检查点 |

## 证据台账

- 记录站点、对象、时间窗、数据定义、来源类型和采集时间。
- 区分平台/账户事实、第三方估算、分析假设与未知项。
- 广告数据写明归因窗口、target、实际搜索词/ASIN、placement 和同期变化。
- SQL 或自动化输出保留版本、参数、行数、检查总量和错误信息。

## 关键检查

- 市场按购买任务而非大类定义
- 信任与证明有具体建设路径
- 竞争和需求数据带估算标签
- 团队、现金和供应能支持试点

## 决策门

- `READY`：证据与对象对齐，当前功能/规则确认，动作可解释可回退。
- `HOLD`：缺一方数据、正确粒度、账户资格、样本或责任人。
- `STOP`：违规、隐私泄露、连接/归因错误、预算越界或不可逆风险。

## 交付模板

1. 任务、站点、对象和时间窗
2. 证据与数据口径
3. 诊断、查询或结构草案
4. 实验/行动与资源边界
5. 风险、停止和回退
6. `READY / HOLD / STOP`
7. 负责人、下一检查和待批准动作

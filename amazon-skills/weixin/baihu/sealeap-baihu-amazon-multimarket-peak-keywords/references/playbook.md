# Amazon 多站点旺季关键词执行手册

## 工作表

| 阶段 | 必须记录 | 通过条件 |
|---|---|---|
| 时间轴 | 当地活动、搜索升温、补货、促销和下架点 | 日期来自目标市场而非国内直觉 |
| 词证据 | 词、语言、意图、来源、窗口、指标 | 每个站点独立留痕 |
| 本地化 | 自然表达、歧义、禁限词、页面承接 | 母语或本地化审核通过 |
| 测试 | 分层、匹配、否定、预算、库存与停止线 | 小规模验证后才扩量 |

## 证据台账字段

- `claim`：当前要支持或反驳的判断。
- `status`：`FACT`、`ESTIMATE`、`ASSUMPTION` 或 `UNKNOWN`。
- `source_type`：Amazon 一方、账户一方、第三方代理、公开观察或用户输入。
- `marketplace/window/sample`：站点、时间窗和样本量。
- `value/unit/definition`：数值、单位和字段定义。
- `limitations`：缺失、延迟、归因、选择偏差和可能的反向解释。
- `decision/owner/next_check`：当前决定、责任人和复核点。

## 指标与计算

- 搜索量、ABA 排名和竞品覆盖注明来源与是否为代理。
- 按站点报告 CTR、CVR、CPC、净贡献及搜索词浪费。
- 用距活动天数和库存覆盖天数监测季节衰减。

公式必须展示输入、单位和窗口；任何经验阈值都标为团队可调参数，并给出悲观、基准和乐观情景。

## 状态门

- `READY`：关键输入完整，政策和账户资格已核实，实验有预算、停止线和回退。
- `HOLD`：方向可能成立，但一个或多个关键证据仍缺失。
- `STOP`：出现硬性违规、不可承受经济性或无法回退的风险。

立即 `STOP` 的典型条件：

- 词只是直译或意图不清。
- Listing 无真实属性承接该词。
- 验证期、补货期或贡献毛利不支持试投。

## 质量检查

- 当前规则与账户状态的检查日期明确；旧截图和旧经验不能冒充当前事实。
- 所有表格使用相同站点、货币、时区、父子体、归因和统计窗口。
- 没有把平台总体数据、第三方估算、个案或相关性写成自身确定结果。
- 草案与实际写入分开；实际变更前展示对象、旧值、新值、影响和回退，确认已有授权覆盖后执行并回读核验；新增范围才另行请求批准。
- 复盘同时呈现成功指标、反证、干扰变量和样本限制。

## 交付模板

1. 任务、站点、对象与时间窗
2. 证据台账与数据口径
3. 诊断或假设
4. 方案/实验及敏感性情景
5. 风险、停止线和回退
6. `READY`、`HOLD` 或 `STOP` 结论
7. 下一步、负责人和待批准动作


## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。
- `广告订单 CVR = 同口径归因订单 / 广告点击`，计算时用小数（10% = 0.10）。每访客购买率、件数转化率与订单 CVR 不可互换；`CPA = CPC / 订单 CVR` 的比较基准是每单广告前贡献，含多件订单时按订单汇总。

# 白虎：广告与受众

本集合包含 10 个独立、可复用的 Amazon 工作流 Skill。`baihu` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-baihu-amazon-display-ads-funnel-plan` | 按拉新、考虑、召回或复购目标选择展示广告定向和指标，用小预算对照测试证明增量，而不是把所有展示流量视为同一种转化来源。 |
| `sealeap-baihu-amazon-amc-audience-activation` | 先证明标准受众无法回答当前问题，再用隐私安全的聚合信号构建可解释的 AMC 人群与增量实验。 |
| `sealeap-baihu-amazon-multimarket-peak-keywords` | 以每个站点的真实搜索表达、季节窗口和单位经济独立建词库，使 Listing 承接与广告测试在旺季前有节奏地验证。 |
| `sealeap-baihu-amazon-peak-event-ad-readiness` | 用活动倒排、商品分层、库存和优惠一致性，把成熟流量与新品学习预算分开。 |
| `sealeap-baihu-amazon-seasonal-keyword-cluster-test` | 按当地节日购买意图聚类关键词并隔离测试，用实际搜索词决定迁移与退出。 |
| `sealeap-baihu-amazon-asin-targeting-map` | 将替代、互补、自家防守和品类发现分组，结合匹配目标报告校准 ASIN 定向。 |
| `sealeap-baihu-amazon-new-market-launch-transfer` | 把源站经验拆成可迁移资产和目标站必须重验的合规、本地化、需求与经济假设。 |
| `sealeap-baihu-amazon-ai-apparel-creative-brief` | 用产品事实和权利约束 AI 服饰素材，逐项核对版型、颜色、人体、Logo 和声明。 |
| `sealeap-baihu-amazon-keyword-to-video-storyboard` | 将高意图搜索词转成问题、演示、证据和行动分镜，并做移动端视频单变量测试。 |
| `sealeap-baihu-amazon-competitor-value-map` | 分开竞品事实、客户反馈和推断，寻找本品能证明且能运营的价值缺口。 |

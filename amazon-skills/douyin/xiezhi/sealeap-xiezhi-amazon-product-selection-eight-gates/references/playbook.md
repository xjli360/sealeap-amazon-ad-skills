# Amazon 选品八道闸门执行手册

## 核心模型

用八个相互独立的门槛把候选从有趣方向推进到可审计立项，任何关键证据缺失都保持 HOLD。

## 工作卡

| 步骤 | 动作 | 做法 | 留痕 |
|---|---|---|---|
| 1 | 精准流量闸 | 必须有能锁定直接竞品和购物意图的属性/对象/场景词。 | 记录证据、判断与停止条件 |
| 2 | 运营难度闸 | 比较低评论正常样本与头部样本，判断新品是否可在合规条件下获得转化。 | 记录证据、判断与停止条件 |
| 3 | 经济效率闸 | 核算广告前贡献、CPA、ACoS、资金占用和周转，不用模糊投产比。 | 记录证据、判断与停止条件 |
| 4 | 差异与供应闸 | 差异有需求证据、搜索页可见且供应商能按质量、成本和 MOQ 实现。 | 记录证据、判断与停止条件 |
| 5 | 时间与周期闸 | 旺季、活动和上架窗口与生产物流倒排一致，并有历史周期证据。 | 记录证据、判断与停止条件 |
| 6 | 合规与 IP 闸 | 完成专利、商标、版权、产品安全、认证、类目和宣传声明核查。 | 记录证据、判断与停止条件 |
| 7 | 库存与变体闸 | 以可达份额、销售窗和变体需求分配首批库存，设置补货和退出条件。 | 记录证据、判断与停止条件 |
| 8 | 总决策 | 汇总每闸证据、置信度与失败成本，只有关键闸均通过才给条件式 GO。 | 记录证据、判断与停止条件 |

## 启发式参考

- 低评论/头部销量比、投产比 120%、未来三到五个月等都属于可调代理指标。
- 任何一个关键闸为 UNKNOWN 时，总结论最多为 HOLD。
- 成功率必须用真实立项的后验结果计算，不能用筛选通过率替代。

这些阈值只能用于提出和排序假设。输出必须同时给出参数变化后的结论是否改变。

## 证据台账字段

- `claim`：要支持的判断。
- `evidence_type`：一方事实、第三方估算、公开证据、用户输入或假设。
- `provider/tool`：数据提供方与实时发现的工具名；不记录密钥。
- `marketplace/window/sample`：站点、时间窗和样本量。
- `value/unit/definition`：数值、单位和字段定义。
- `confidence/limitations`：可信度、偏差方向和缺口。
- `decision/owner/next_check`：当前结论、责任人和下一次复核点。

## 质量检查

- 直接竞品由相同购买对象、场景、核心属性和价格带定义，而不是搜索结果总数。
- 同一表格内销量、点击、访客、订单、父体与子体口径保持一致。
- 对异常评价、合并变体、极端促销、站外流量和季节事件作单独标记。
- 任何公式展示输入、单位、时间窗和敏感性区间。
- 每个 GO 建议同时给出失败条件、止损和下一步验证。
- 采购、发布或账户写操作仍需独立批准。

## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。
- `广告订单 CVR = 同口径归因订单 / 广告点击`，计算时用小数（10% = 0.10）。每访客购买率、件数转化率与订单 CVR 不可互换；`CPA = CPC / 订单 CVR` 的比较基准是每单广告前贡献，含多件订单时按订单汇总。
- `ACoS = 广告花费 / 归因销售额`；`TACoS = 广告花费 / 同范围总销售额`，两者不能互换。保本 ACoS 的分母也使用同口径归因销售额，净收入、含税收入与扣退货收入不得混用。

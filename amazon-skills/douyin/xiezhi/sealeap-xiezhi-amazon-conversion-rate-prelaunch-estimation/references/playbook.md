# Amazon 上市前转化率估算执行手册

## 核心模型

用头部链接和细分市场两种口径交叉估算转化率，再判断保本 CVR 是否现实。

## 工作卡

| 步骤 | 动作 | 做法 | 留痕 |
|---|---|---|---|
| 1 | 统一单位经济 | 计算广告前贡献毛利、盈亏平衡 CPA、ACoS 和所需 CVR，并明确税费、退款和优惠口径。 | 记录证据、判断与停止条件 |
| 2 | 估单品 CVR | 只有订单与点击来自相同流量范围、对象、时间窗和归因口径时才估算订单 CVR。全渠道销量除以搜索点击只能标为需求比例代理，不能作为 CVR 或直接代入 CPA；缺少可比样本时用明确标注的假设区间并保留 HOLD。 | 记录证据、判断与停止条件 |
| 3 | 估市场 CVR | 读取细分市场购买率、转化购买率或等价一方指标，解释访客、点击、归因窗差异。 | 记录证据、判断与停止条件 |
| 4 | 形成区间 | 不机械取单点，使用保守/基准/乐观三档并剔除口径不可比样本。 | 记录证据、判断与停止条件 |
| 5 | 做立项闸门 | 若头部或市场基准仍低于保本 CVR，则 HOLD；只有差异化能被证据支持时才建立例外情景。 | 记录证据、判断与停止条件 |

## 启发式参考

- CPA = CPC / 订单 CVR；保本订单 CVR = CPC / 广告前每单贡献毛利。贡献毛利非正、分母为零或所需 CVR 超过 100% 时，标为当前经济模型不可行。
- 搜索点击口径通常不能代表全部流量，单 ASIN 结果必须标注偏差方向。
- 购买率与转化购买率定义可能随报表变化，必须记录当前官方字段说明。
- 头部转化差时，新品默认不能假设显著优于头部。

这些阈值只能用于提出和排序假设。输出必须同时给出参数变化后的结论是否改变。

## 证据台账字段

- `claim`：要支持的判断。
- `evidence_type`：一方事实、第三方估算、公开证据、用户输入或假设。
- `provider/tool`：数据提供方与实时发现的工具名；不记录密钥。
- `marketplace/window/sample`：站点、时间窗和样本量。
- `value/unit/definition`：数值、单位和字段定义。
- `confidence/limitations`：可信度、偏差方向和缺口。
- `decision/owner/next_check`：当前结论、责任人和下一次复核点。

## 质量检查

- 直接竞品由相同购买对象、场景、核心属性和价格带定义，而不是搜索结果总数。
- 同一表格内销量、点击、访客、订单、父体与子体口径保持一致。
- 对异常评价、合并变体、极端促销、站外流量和季节事件作单独标记。
- 任何公式展示输入、单位、时间窗和敏感性区间。
- 每个 GO 建议同时给出失败条件、止损和下一步验证。
- 采购、发布或账户写操作仍需独立批准。

## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。
- `广告订单 CVR = 同口径归因订单 / 广告点击`，计算时用小数（10% = 0.10）。每访客购买率、件数转化率与订单 CVR 不可互换；`CPA = CPC / 订单 CVR` 的比较基准是每单广告前贡献，含多件订单时按订单汇总。
- `ACoS = 广告花费 / 归因销售额`；`TACoS = 广告花费 / 同范围总销售额`，两者不能互换。保本 ACoS 的分母也使用同口径归因销售额，净收入、含税收入与扣退货收入不得混用。

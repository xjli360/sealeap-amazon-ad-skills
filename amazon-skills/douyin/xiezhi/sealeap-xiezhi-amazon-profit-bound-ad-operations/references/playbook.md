# Amazon 盈利边界广告运营执行手册

## 核心模型

从选品阶段就限定精准流量和可承受点击，用小型广告结构寻找每个 SKU 的盈利流量区间，并及时降级失败品。

## 工作卡

| 步骤 | 动作 | 做法 | 留痕 |
|---|---|---|---|
| 1 | 设盈利边界 | 计算保本 CPC、CPA 和 ACoS，并为目标利润留安全余量。 | 记录证据、判断与停止条件 |
| 2 | 精简结构 | 每个活动放少量同意图词；大流量词必要时独立，确保预算和结果可归因。 | 记录证据、判断与停止条件 |
| 3 | 控制学习 | 预算覆盖预设样本即可，不追求大量流量；记录归因窗和累计亏损。 | 记录证据、判断与停止条件 |
| 4 | 先调位置 | 样本充分后比较广告位，再通过基础竞价与位置系数让流量向高质量位置倾斜。 | 记录证据、判断与停止条件 |
| 5 | 再调词 | 高相关低效词隔离复测，不相关词否定，已验证查询从广泛迁入精准。 | 记录证据、判断与停止条件 |
| 6 | 管理 SKU 状态 | 盈利且可补货的放大；接近边界的维持；长期不可盈利的降级到低投入或停止。 | 记录证据、判断与停止条件 |

## 启发式参考

- 每日约 20–30 次点击或一至两周观察只是样例，样本应由预期 CVR、预算和损失上限决定。
- 流量增加后 CVR 下滑可能来自查询/广告位变化，不能直接归因于隐藏人群配额。
- 广告目标是贡献利润与可持续周转，不是单独追求 BSR 或最低 ACoS。

这些阈值只能用于提出和排序假设。输出必须同时给出参数变化后的结论是否改变。

## 证据台账字段

- `claim`：要支持的判断。
- `evidence_type`：一方事实、第三方估算、公开证据、用户输入或假设。
- `provider/tool`：数据提供方与实时发现的工具名；不记录密钥。
- `marketplace/window/sample`：站点、时间窗和样本量。
- `value/unit/definition`：数值、单位和字段定义。
- `confidence/limitations`：可信度、偏差方向和缺口。
- `decision/owner/next_check`：当前结论、责任人和下一次复核点。

## 质量检查

- 直接竞品由相同购买对象、场景、核心属性和价格带定义，而不是搜索结果总数。
- 同一表格内销量、点击、访客、订单、父体与子体口径保持一致。
- 对异常评价、合并变体、极端促销、站外流量和季节事件作单独标记。
- 任何公式展示输入、单位、时间窗和敏感性区间。
- 每个 GO 建议同时给出失败条件、止损和下一步验证。
- 采购、发布或账户写操作仍需独立批准。

## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。
- `广告订单 CVR = 同口径归因订单 / 广告点击`，计算时用小数（10% = 0.10）。每访客购买率、件数转化率与订单 CVR 不可互换；`CPA = CPC / 订单 CVR` 的比较基准是每单广告前贡献，含多件订单时按订单汇总。
- `ACoS = 广告花费 / 归因销售额`；`TACoS = 广告花费 / 同范围总销售额`，两者不能互换。保本 ACoS 的分母也使用同口径归因销售额，净收入、含税收入与扣退货收入不得混用。

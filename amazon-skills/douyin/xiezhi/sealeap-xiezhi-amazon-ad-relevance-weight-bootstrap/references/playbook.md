# Amazon 广告相关性启动执行手册

## 核心模型

用精准购物意图、页面一致性和受控学习预算积累可解释的点击与转化信号，而不是依赖未经证实的权重公式。

## 工作卡

| 步骤 | 动作 | 做法 | 留痕 |
|---|---|---|---|
| 1 | 建立相关性地图 | 将产品核心属性、对象和场景与搜索词、Listing 标题/要点和目标页面逐项对齐。 | 记录证据、判断与停止条件 |
| 2 | 选择启动词 | 优先购买意图明确且搜索结果高度一致的词，排除大而泛、与产品弱相关的流量。 | 记录证据、判断与停止条件 |
| 3 | 设置学习护栏 | 以建议竞价区间为参考制定小范围测试，预先限定日预算、累计花费、最低样本和停止条件。 | 记录证据、判断与停止条件 |
| 4 | 观察分层信号 | 分别看曝光、CTR、CVR、CPC、广告位和搜索词；先判断资格/相关性，再判断商品页和价格。 | 记录证据、判断与停止条件 |
| 5 | 逐步调整 | 一次只改变主要变量；只有转化证据支持时扩大预算或竞价，表现恶化则回退。 | 记录证据、判断与停止条件 |

## 启发式参考

- 广告排序受出价、相关性、预计效果和竞争环境共同影响；不存在可直接读取的固定单一权重分。
- 新品可进行受控学习，但不得无上限高价抢位或把前三天当作必然起量窗口。
- 盈亏 CPC = 广告前每单贡献毛利 × 订单 CVR；订单 CVR 按归因订单 / 点击，以小数代入。出价与实际 CPC 分开，并检查动态竞价和位置调整后的风险。

这些阈值只能用于提出和排序假设。输出必须同时给出参数变化后的结论是否改变。

## 证据台账字段

- `claim`：要支持的判断。
- `evidence_type`：一方事实、第三方估算、公开证据、用户输入或假设。
- `provider/tool`：数据提供方与实时发现的工具名；不记录密钥。
- `marketplace/window/sample`：站点、时间窗和样本量。
- `value/unit/definition`：数值、单位和字段定义。
- `confidence/limitations`：可信度、偏差方向和缺口。
- `decision/owner/next_check`：当前结论、责任人和下一次复核点。

## 质量检查

- 直接竞品由相同购买对象、场景、核心属性和价格带定义，而不是搜索结果总数。
- 同一表格内销量、点击、访客、订单、父体与子体口径保持一致。
- 对异常评价、合并变体、极端促销、站外流量和季节事件作单独标记。
- 任何公式展示输入、单位、时间窗和敏感性区间。
- 每个 GO 建议同时给出失败条件、止损和下一步验证。
- 采购、发布或账户写操作仍需独立批准。

## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。
- `广告订单 CVR = 同口径归因订单 / 广告点击`，计算时用小数（10% = 0.10）。每访客购买率、件数转化率与订单 CVR 不可互换；`CPA = CPC / 订单 CVR` 的比较基准是每单广告前贡献，含多件订单时按订单汇总。

# Amazon 竞品关键词结构审计 Playbook

## 适用问题

Use for 竞品广告词分析、反查竞品关键词、判断精准词与探索词、找防守或捡漏词. Do not claim unseen campaign settings as facts.

## 输入证据

- marketplace、产品事实、ASIN/SKU 与目标购买意图
- 本品和可比竞品的关键词、自然位置、广告可见度与采样时间
- 搜索词报告、转化、CPC、订单、利润和 Listing 当前覆盖
- 站点语言、变体、价格、库存与同期促销记录

## 决策路径

1. 选择功能、外观、价格和评价基础足够接近的竞品。
2. 分开记录自然可见度、广告可见度、词义相关性和采样时间。
3. 重复属性词可作为词组或广泛策略线索；杂乱查询只作为自动流量假设。
4. 优先找自然表现强、语义匹配但广告覆盖弱的候选词。
5. 对自然靠后或无自然证据的广告词做低相关风险复核，而非自动否定。

## 经验假设与降级规则

- 前台观测不能反推出竞品后台匹配类型、竞价或预算。
- 自然排名高也可能来自品牌、历史或变体因素，必须核对本品适配。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 竞品词证据表
- 结构假设与置信度
- 捡漏候选
- 本品验证计划
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。

# Amazon 红海类目细分机会 Playbook

## 适用问题

Use for 红海里找蓝海、化妆包等细分类目、低评论销量、广告效率、运营难度. Not for copying or review merging.

## 输入证据

- 目标 marketplace、类目、价格带、上架时间与运营模式
- 候选品与同购买意图可比样本的销量、评论、价格和上架时间
- 关键词需求、历史趋势、广告依赖、同款密度和品牌集中度
- 采购、头程、平台费、退货、仓储、交期和合规/IP 基础信息

## 决策路径

1. 在目标类目中按功能、结构、尺寸、场景或人群切出具体购买任务。
2. 检查该切片中低评论商品是否仍能稳定销售。
3. 比较销量与广告词覆盖的相对效率，并排除品牌或站外流量偏差。
4. 评估评论成熟度与头部差距，形成可承接销量区间。
5. 寻找可合法开发的差异点，并补 IP、利润和供应链验证。

## 经验假设与降级规则

- 评论合并、变体滥用或人为干预只能列为风险线索，不能模仿。
- 广告词数量来自第三方观测，口径不一致时不得直接比较。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 细分机会树
- 低评论证据
- 广告效率代理
- 合规差异化方向
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

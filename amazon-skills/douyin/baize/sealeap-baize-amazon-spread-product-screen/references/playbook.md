# Amazon 精铺候选品快筛 Playbook

## 适用问题

Use for 精铺选品、低库存多产品模式、首批备货、运营难度快筛. Formal investment decisions require broader research.

## 输入证据

- 目标 marketplace、类目、价格带、上架时间与运营模式
- 候选品与同购买意图可比样本的销量、评论、价格和上架时间
- 关键词需求、历史趋势、广告依赖、同款密度和品牌集中度
- 采购、头程、平台费、退货、仓储、交期和合规/IP 基础信息

## 决策路径

1. 先定义可接受的单品订单、利润和库存风险，而不是从高销量榜单开始。
2. 检查未来需求窗口和老品历史趋势，排除到货时需求已回落的方向。
3. 在有足够市场深度的方向中寻找功能、尺寸、组合或场景切片。
4. 按低评论样本相对头部表现、广告依赖和同款密度估算运营难度。
5. 用保守销量中位值反推首批库存，并设置补货与清仓触发线。

## 经验假设与降级规则

- 第三方销量、上架时间和关键词均为估算，需要交叉验证。
- 快筛不覆盖专利、合规、供应链和完整单位经济，结论只能是进入调研、观察或淘汰。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 候选切片表
- 运营难度证据
- 保守销量区间
- 首批库存边界
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

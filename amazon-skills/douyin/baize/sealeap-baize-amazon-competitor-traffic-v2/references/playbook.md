# Amazon 竞品流量网络进阶版 Playbook

## 适用问题

Use for 系统化抢竞品流量、自然强但广告弱的词、竞品核心词、防守词、自动捡漏. Use v1 only for a simpler audit.

## 输入证据

- marketplace、产品事实、ASIN/SKU 与目标购买意图
- 本品和可比竞品的关键词、自然位置、广告可见度与采样时间
- 搜索词报告、转化、CPC、订单、利润和 Listing 当前覆盖
- 站点语言、变体、价格、库存与同期促销记录

## 决策路径

1. 先验证竞品可替代性、同站点购买意图和本品承接能力。
2. 把自然强广告弱的相关词与自然和广告都强的相关词分成独立精准层。
3. 从可靠词集中提取属性与场景词根，建立低风险探索层。
4. 自动发现层使用独立低预算，基于实际搜索词清理低相关匹配。
5. 同步检查本品自然强但广告覆盖弱的词，形成防守层。
6. 各层分别定义出价逻辑、预算、样本、利润和停止条件。

## 经验假设与降级规则

- 固定排名位次、建议价倍数、位置倍率和自动组数都必须用实时数据校准。
- Listing 中应准确写明属性与场景，但不能为了匹配而堆词。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 竞品适配门槛
- 五层流量架构
- 逐层实验契约
- 防守与退出规则
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。

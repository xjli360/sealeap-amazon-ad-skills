# Amazon 广告策略路由 Playbook

## 适用问题

Use for 不同产品怎么选广告打法、服装多变体、泛流量品、无明确关键词产品、保守或进攻策略.

## 输入证据

- marketplace、店铺、ASIN/SKU、广告类型和目标
- 同口径的 Campaign、Targeting、Search Term、Placement 与 Advertised Product 报告
- 售价、优惠、COGS、Amazon 费用、退款与目标贡献利润
- 库存、Buy Box、Listing、评论和同期市场事件

## 决策路径

1. 先判断产品是否有明确属性词、只有宽泛场景词，或主要依靠相似商品流量。
2. 有明确属性词时用精准核心词和受控词根扩展；泛流量品分开探索。
3. 无明确关键词时以高度相似 ASIN 和自动发现为小预算入口。
4. 根据利润、转化、库存与增长目标选择盈利、进攻或保守模式。
5. 运行后按真实 CPC、CVR 和总利润重新分类，不固守上线前标签。

## 经验假设与降级规则

- 品类或变体数量不直接决定广告结构，购买意图和可隔离证据才决定。
- 宽泛流量必须有独立预算和回退线。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 产品流量类型
- 广告结构路由
- 经营模式选择
- 重分类触发器
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。
- `广告订单 CVR = 同口径归因订单 / 广告点击`，计算时用小数（10% = 0.10）。每访客购买率、件数转化率与订单 CVR 不可互换；`CPA = CPC / 订单 CVR` 的比较基准是每单广告前贡献，含多件订单时按订单汇总。

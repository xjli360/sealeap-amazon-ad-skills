# Amazon AI 商品图工作流 Playbook

## 适用问题

Use for AI做亚马逊商品图、主图差异化、副图和A+规划、评论洞察转视觉、图片测款. Not for fabricating the product.

## 输入证据

- 目标 marketplace、产品事实、品牌语气和当前政策约束
- 已授权的 Listing、关键词、评论/VOC、图片和竞品证据
- 每项数据的来源、时间、站点、样本和限制
- 人工审核人、发布边界和不可生成的声明或视觉特征

## 决策路径

1. 收集产品事实、实拍素材、竞品页面和合规评论洞察。
2. 提炼购买动机、异议、使用场景和一个可视化差异点。
3. 先生成逐张副图和 A+ brief：目标、构图、文案、证据、素材和禁改项。
4. AI 仅产出构图与效果草案，产品主体用真实照片或核准 3D 素材替换。
5. 主图单独按当前站点规则审核白底、占比、文字、道具和准确性。
6. 把视觉概念用于未来改款时，与当前在售 Listing 严格区分。

## 经验假设与降级规则

- 不得改变商品尺寸、颜色、结构、数量、配件或效果来提高转化。
- 公开评论抓取需遵守条款、隐私与最小化原则；优先使用自有授权数据。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 视觉证据板
- 逐张图片 brief
- 主图合规清单
- 实物一致性审核
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

# Amazon AI Listing 生产线 Playbook

## 适用问题

Use for AI写Listing、关键词表清洗、竞品词过滤、广告词选择、标题五点和后台词草拟. Not for invented claims or direct publishing.

## 输入证据

- 目标 marketplace、产品事实、品牌语气和当前政策约束
- 已授权的 Listing、关键词、评论/VOC、图片和竞品证据
- 每项数据的来源、时间、站点、样本和限制
- 人工审核人、发布边界和不可生成的声明或视觉特征

## 决策路径

1. 输入产品事实、目标站点、相似竞品和带来源的关键词表。
2. 清理空值与明显不相关词，再以自然可见度形成候选集。
3. 让模型逐词对照多个竞品属性和本品事实，输出保留或删除理由。
4. 区分精准广告候选、探索词根、Listing 前台词和后台词。
5. 按购买决策顺序生成标题、要点和描述，并附关键词与事实映射。
6. 人工复核字符限制、敏感声明和目标站点当前规则。

## 经验假设与降级规则

- 自然位置只是筛选先验；词义和产品事实决定能否使用。
- AI 不得补造材质、尺寸、认证、功效、比较或促销信息。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 清洗日志
- 关键词去向表
- Listing 草稿
- 事实与声明审计
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

# Amazon 断货后流量恢复 Playbook

## 适用问题

Use for 补货后转化变差、断货后自然流量掉了、广告重启、受众重新校准. Do not use for review or order manipulation.

## 输入证据

- marketplace、ASIN/SKU、库存阶段、补货与到仓时间
- 断货或备货前后的销量、流量、广告、自然位置和转化基线
- COGS、头程、仓储、平台费、退货和清仓成本
- 可比产品的成熟度、销量区间和需求趋势

## 决策路径

1. 保存断货前稳定期、断货期和补货后的同口径数据快照。
2. 区分自然曝光、关联商品页流量、关键词广告和受众流量的变化。
3. 先恢复历史上最精准的手动词，并以低风险流量验证页面承接。
4. 仅对功能、价格与评价基础接近的商品做隔离式 ASIN 测试。
5. 转化稳定后分阶段恢复探索流量、促销和预算，每次只改一个变量。

## 经验假设与降级规则

- 不抓取客户邮箱、不购买评论、不刷单、不使用所谓测评订单恢复权重。
- 断货导致画像变化属于待验证解释，应以实际流量结构变化为证据。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 三阶段损失诊断
- 精准重启清单
- 恢复阶梯
- 合规禁区与回退线
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

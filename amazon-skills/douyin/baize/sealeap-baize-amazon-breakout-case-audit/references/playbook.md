# Amazon 爆款案例因果审计 Playbook

## 适用问题

Use for 爆款案例复盘、为什么突然增长、是不是站外、能不能复制、成功因素拆解.

## 输入证据

- 目标 marketplace 与案例 ASIN 的明确时间范围
- 销量、评论、价格、促销、变体和上架时间线
- 关键词自然/广告可见度、品牌与站外流量代理证据
- 可复核来源、数据口径、缺失项和替代解释

## 决策路径

1. 先列出功能、品牌、价格、流量、时机、变体和促销等互斥或并存解释。
2. 用关键词自然覆盖、销量评论时间线和市场需求逐项证伪。
3. 区分相关事件与可归因因素，不从结果倒推唯一原因。
4. 识别不可复制条件、合规风险和幸存者偏差。
5. 将可迁移部分转成产品、页面、选词和位置实验。

## 经验假设与降级规则

- 不模仿评论合并、变体滥用、刷单或其他人为干预。
- 第三方历史数据不能证明后台真实操作或违规行为。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 候选因果树
- 证据与反证
- 可复制与不可复制项
- 合规实验
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

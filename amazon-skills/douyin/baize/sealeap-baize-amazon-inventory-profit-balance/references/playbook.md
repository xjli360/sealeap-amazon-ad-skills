# Amazon 库存与利润平衡 Playbook

## 适用问题

Use for 首批发多少、库存临界点、精铺盈利逻辑、广告花费怎么控、多产品组合风险.

## 输入证据

- marketplace、ASIN/SKU、库存阶段、补货与到仓时间
- 断货或备货前后的销量、流量、广告、自然位置和转化基线
- COGS、头程、仓储、平台费、退货和清仓成本
- 可比产品的成熟度、销量区间和需求趋势

## 决策路径

1. 用低成熟度可比产品估算销量区间，而不是直接采用头部销量。
2. 计算不同备货量下的现金占用、仓储、广告和清仓损失。
3. 用单位贡献利润反推最大广告获客成本。
4. 在单 SKU 和组合层分别设置补货、减投和退出触发器。
5. 滚动更新实际销量与转化，逐批增加而非一次压货。

## 经验假设与降级规则

- 不存在可验证的固定店铺订单上限时，不用该假设限制组合。
- 固定广告占比是经验值，应按产品毛利、退货和目标利润重算。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 销量区间
- 库存情景表
- 获客成本上限
- 组合风险与触发器
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

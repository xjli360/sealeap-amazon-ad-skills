# Amazon 精品广告节奏 Playbook

## 适用问题

Use for 精品怎么投广告、低评论新品、追求高投产、什么时候减少或扩大广告. Do not use review manipulation.

## 输入证据

- marketplace、店铺、ASIN/SKU、广告类型和目标
- 同口径的 Campaign、Targeting、Search Term、Placement 与 Advertised Product 报告
- 售价、优惠、COGS、Amazon 费用、退款与目标贡献利润
- 库存、Buy Box、Listing、评论和同期市场事件

## 决策路径

1. 先验证产品差异、单位经济、低评论竞争力和可承接的精准需求。
2. 从最相关的属性词开始，避免用自动或大词掩盖真实转化。
3. 启动期用有限预算验证 CPC、位置和页面承接。
4. 转化不足先减少无效流量并修产品页；转化稳定后再扩大。
5. 用总订单、TACOS、利润和库存周转共同判断节奏。

## 经验假设与降级规则

- 不购买、交换或诱导评论；使用 Vine 等合规路径也要核对资格与当前规则。
- 精品是经营策略，不等于高售价或精美图片。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 精品资格门槛
- 启动节奏
- 缩量与扩量触发器
- 利润和库存护栏
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。

- `ACoS = 广告花费 / 归因销售额`；`TACoS = 广告花费 / 同范围总销售额`，两者不能互换。保本 ACoS 的分母也使用同口径归因销售额，净收入、含税收入与扣退货收入不得混用；分母为零或缺失时记为不可计算。

# Amazon 自然排名提升实验 Playbook

## 适用问题

Use for 推关键词自然排名、选择推词变体、自然第一后是否停广告、精准词放量. Do not use artificial orders.

## 输入证据

- marketplace、产品事实、ASIN/SKU 与目标购买意图
- 本品和可比竞品的关键词、自然位置、广告可见度与采样时间
- 搜索词报告、转化、CPC、订单、利润和 Listing 当前覆盖
- 站点语言、变体、价格、库存与同期促销记录

## 决策路径

1. 确认目标词与本品属性、用途和站点语言一致，并有转化竞争力。
2. 从本品已有自然信号与相似竞品词表中选择少量候选。
3. 前台检查目标词实际展示的变体，选择最匹配子体。
4. 用隔离广告支持目标词，同时监测自然位置、总转化、TACOS 与利润。
5. 达到目标后阶梯降价或停投，判断广告是否仍带来增量。

## 经验假设与降级规则

- 不使用刷单、人为下单或评论操纵推词。
- 排名公式、权重大小和固定自然位门槛均视为假设。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 目标词资格
- 变体选择
- 排名实验卡
- 广告增量结论
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

## 自然与增量证据口径

只把报告明确区分的自然指标称为实测自然量。总订单与广告归因订单在日期、窗口、购买 ASIN 或去重范围不一致时，不能相减得到自然订单；可比但不完全可识别的差额仍标为代理值。没有查询级数据时使用可观测的 ASIN 总量与重复排名采样，不补造自然词级订单。前后变化需要记录价格、季节、库存和竞争干扰，不能直接当作广告增量。

## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。

- `ACoS = 广告花费 / 归因销售额`；`TACoS = 广告花费 / 同范围总销售额`，两者不能互换。保本 ACoS 的分母也使用同口径归因销售额，净收入、含税收入与扣退货收入不得混用；分母为零或缺失时记为不可计算。

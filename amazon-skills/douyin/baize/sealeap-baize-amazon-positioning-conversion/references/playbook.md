# Amazon 定位与页面转化提升 Playbook

## 适用问题

Use for 主图差异化、评论洞察、标题五点优化、同质化产品重新定位、提升转化.

## 输入证据

- marketplace、ASIN/SKU、产品事实和当前 Listing
- 同购买意图可比竞品、价格、评论、图片和销量
- Search Term、Placement、CTR、CVR、订单、退货和利润
- VOC、Q&A、退货原因与任何页面或广告变更日志

## 决策路径

1. 从自有评论、退货原因和相似竞品评论提取购买动机、异议和未满足需求。
2. 选择一个能由实物事实证明、且缩略图可表达的定位。
3. 按该定位重写图片 brief、标题和要点，建立事实到文案映射。
4. 选择与新定位一致的精准词，不用大流量词掩盖承接问题。
5. 页面与广告实验分开，监测 CTR、CVR、退货和利润。

## 经验假设与降级规则

- 单个成功案例不能证明方法普遍有效。
- 图片不得改变实物结构、尺寸、颜色、配件或效果。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- VOC 证据表
- 定位陈述
- 页面字段草案
- 转化实验与护栏
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

## 指标口径补充

- 所有比率先统一站点、货币、对象、流量范围与归因窗口；分母为零或缺失时记为不可计算，不能解释为零成本或无限效率。
- `广告订单 CVR = 同口径归因订单 / 广告点击`，计算时用小数（10% = 0.10）。每访客购买率、件数转化率与订单 CVR 不可互换；`CPA = CPC / 订单 CVR` 的比较基准是每单广告前贡献，含多件订单时按订单汇总。

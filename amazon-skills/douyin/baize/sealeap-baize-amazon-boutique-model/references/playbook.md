# Amazon 精品商业模型 Playbook

## 适用问题

Use for 什么是精品、精品选品框架、资金周转、市场健康度、精品是否成立. Do not reduce boutique strategy to premium creative.

## 输入证据

- 目标 marketplace、类目、价格带、上架时间与运营模式
- 候选品与同购买意图可比样本的销量、评论、价格和上架时间
- 关键词需求、历史趋势、广告依赖、同款密度和品牌集中度
- 采购、头程、平台费、退货、仓储、交期和合规/IP 基础信息

## 决策路径

1. 先定义资金回收、利润和库存周转目标。
2. 用主题、关键词需求或使用背景发现能避开同质化的细分。
3. 验证垂直流量、相对定价、在售同款密度和尾部转化。
4. 检查价格分布、品牌集中、异常促销和进入壁垒。
5. 将产品结论放入保守、可测试或不进入三档。

## 经验假设与降级规则

- 任何固定饱和度系数都只算探索线索，必须用当前样本校准。
- 大类目汇总会掩盖价格和功能切片，应在真实购买任务层分析。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 商业模型卡
- 细分市场证据
- 周转与亏损边界
- 进入决策
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

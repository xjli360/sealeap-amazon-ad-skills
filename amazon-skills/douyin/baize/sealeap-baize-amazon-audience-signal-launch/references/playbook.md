# Amazon 新品受众信号控制 Playbook

## 适用问题

Use for 新品人群标签、用户画像、相同关键词转化不同、展示或视频广告受众、前期控流量.

## 输入证据

- marketplace、ASIN/SKU、产品事实与目标购买任务
- 关键词、商品投放、展示和视频的聚合表现
- 受众包定义、资格、站点限制和隐私边界
- 价格、评论、页面、库存与转化基线

## 决策路径

1. 把所谓人群标签改写为可观测的查询、商品页、受众包和转化行为。
2. 启动期优先高意图属性词，控制宽泛流量占比。
3. 商品投放只选替代性和价格评价基础接近的对象。
4. 展示与视频受众使用独立预算，并记录受众资格与站点限制。
5. 若精准流量长期仍差，回到价格、评论、图片与产品竞争力。

## 经验假设与降级规则

- 不得声称能看见个体画像或平台内部标签。
- 受众推断必须保持聚合、隐私安全并接受产品根因的可能性。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 流量来源图
- 受众相关性假设
- 启动配比
- 产品侧回查条件
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

# Amazon 广告与自然订单归因 Playbook

## 适用问题

Use for 广告单挤占自然单、关广告会不会掉单、哪些词可停、自然订单怎么算、整体广告盈利.

## 输入证据

- marketplace、ASIN/SKU、广告归因窗与业务报告时间窗
- 广告订单、总订单、会话、自然位置、TACOS 与贡献利润
- 价格、优惠、库存、Buy Box、Listing 和评论变更日志
- 查询、广告位和投放对象的相关性证据

## 决策路径

1. 统一 ASIN、站点、归因窗和业务报告日期，先看总订单与贡献利润。
2. 记录广告点击带来的详情页曝光和后续非直接归因影响，但标为假设。
3. 仅在自然位、价格、库存和页面稳定时做阶梯降价或停投实验。
4. 比较广告订单下降后自然订单是否补回、总单是否稳定、利润是否改善。
5. 不因某词短期未归因订单就自动否定；先检查相关性和样本。

## 经验假设与降级规则

- 自然订单不能简单等同于会话订单减广告订单，报表口径和归因窗可能不同。
- 第三方关键词数据之间可能口径冲突，保留各来源而非强行合并。

- 出现固定阈值、平台算法解释或因果结论时，改为待验证假设，并用当前站点与账户数据校准。
- 数据源冲突时保留各自口径，不取没有依据的平均数，也不选择更好看的结果。
- 第三方工具不可用、额度不足或 schema 改变时，记录缺口并停止；不得伪造调用结果。

## 输出检查

- 口径对齐表
- 增量性实验
- 词级保留与暂停理由
- 利润变化
- 每项建议都能回指当前任务中的证据或明确假设。
- 对未授权的线上变更保留草案；用户已有授权覆盖明确对象、动作与预算时可执行，并记录实际结果与回读证据。

## 自然与增量证据口径

只把报告明确区分的自然指标称为实测自然量。总订单与广告归因订单在日期、窗口、购买 ASIN 或去重范围不一致时，不能相减得到自然订单；可比但不完全可识别的差额仍标为代理值。没有查询级数据时使用可观测的 ASIN 总量与重复排名采样，不补造自然词级订单。前后变化需要记录价格、季节、库存和竞争干扰，不能直接当作广告增量。

## 指标口径补充


- `ACoS = 广告花费 / 归因销售额`；`TACoS = 广告花费 / 同范围总销售额`，两者不能互换。保本 ACoS 的分母也使用同口径归因销售额，净收入、含税收入与扣退货收入不得混用；分母为零或缺失时记为不可计算。

# Amazon Woot Deal 可行性评估

## 目标

把 Woot 视为独立销售与促销渠道，核对官方准入、真实利润和责任边界，而不是风险隔离工具。

## 适用任务

- 服务商提供 Woot 入驻、代报或账号出售。
- 评估新品或库存参加 Woot 活动。
- 比较 Woot 核价、费用、库存和品牌影响。

## 开始前要拿到

- 当前 Woot 官方卖家或供应商准入信息和合同。
- 主体、账号所有权、品牌授权、ASIN、库存与物流责任。
- 核价、折扣、费用、退货、结算和活动后影响。

缺失的数据要明确列为缺口，并把结论标成事实、估算或假设；不要补造数字。

## 不可妥协的边界

- 不得购买、出售、借用或代持账号，也不得规避主体审核。
- Woot 不是评论操纵、虚假订单或绩效风险的防火墙。
- 所有资格、费用和流程容易变化，必须用当前官方材料验证。
- 当前 Amazon 官方政策、帮助页、账户资格和后台实际字段优先于本 Skill 中的经验框架；规则可能变化时先核验。
- 默认提供诊断或草案。写入前展示对象、旧值、新值、影响、停止线与回退，核对用户已有授权是否覆盖对象、动作与预算；范围已明确授权时继续执行并回读核验，只有未覆盖或扩大的范围才请求批准。
- 不输出原素材的创作者身份、账号、链接、视频编号或可反查线索；当前业务证据的官方来源、采集时间和口径仍需保留。

## 工作流

### 1. 验证准入来源

确认申请或邀请来自 Woot 官方域名和合同主体，核验服务商授权与费用，不分享凭证。

### 2. 核对账号与权利

确认实际经营主体、银行税务信息、品牌或分销权和商品真实性。

### 3. 计算 Deal 经济性

从核价扣除费用、货值、物流、退货、仓储和机会成本，计算贡献利润与现金周期。

### 4. 评估库存与品牌

检查活动量、补货、价格历史、其他渠道冲突和活动后 Amazon 价格感知。

### 5. 审查合规风险

排除人工订单、评价干预、跟卖隔离风险和任何账号交易安排。

### 6. 形成条件式决策

资格、利润、库存、权利和运营能力均通过才给 GO；否则给补件或 NO-GO。

## 判断标准

- 官方资格和合同已当前验证。
- 账号、款项和商品权利链一致。
- 活动在压力情景下仍不突破亏损和库存线。

## 必须交付的结果

- 准入与服务商真实性检查。
- Deal 单位经济和现金周期。
- 库存、品牌与合规风险。
- GO、CONDITIONAL GO 或 NO-GO。

结尾列出数据窗口、关键假设、证据缺口、风险和下一步；如包含待执行动作，单独放在“待批准变更”中。

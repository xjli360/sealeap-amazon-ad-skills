# Amazon 选品记分卡：核心指标、冷门切入与工厂合作：专项证据卡

本文件汇总该组内相近主题的 7 张证据卡，每张卡对应一个去标识化语义单元。以下是分析台账字段，不是可直接传给某个 API 的参数；取数前需映射到实时 schema。只加载当前问题直接相关的卡片，不要无差别执行全部内容。

## 低客单价非标品的运营特征

- 判断要求：低客单价非标品流量分散、转化率天然低于标品、受节日季节波动大、竞争与仿制多、利润薄且 SKU 管理复杂；运营重点是流量预测、低成本精准引流和成本与 SKU 管理，而不是单品排名。
- 方法要点：
  - 确认产品属于该类型：单价低、可比选择多、买家有浏览比较习惯。
  - 广告结构以商品推广加展示型推广做低成本精准引流，或商品推广加品牌推广承接中长尾词。
  - 建立流量预测与季节日历，提前调整预算与库存。
  - 用款式与规格丰富度换取总量，同时用 SKU 级利润表淘汰亏损款。
  - 为仿制与代工冲击准备知识产权与差异化对策。
- 待验证与降级：
  - 转化率‘非标低于标品’是结构性倾向，具体差距需类目数据。
  - 广告组合方式需按账户资格与预算验证。
- 最小证据字段：`marketplace`, `category`, `price_band`, `sku_count`, `cvr`, `seasonality_index`, `ad_mix`, `margin_per_sku`, `window`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 选品记分卡的核心与加分项

- 判断要求：选品核心指标只有四个：评论依赖度、净利润率、同行推广手段、新品预估 ACOS；增量市场、垄断度、评论质量、退货率、体量上限、利润下限等都是加分项而非否决项。
- 方法要点：
  - 评论依赖度：判断该细分是否必须有大量评论才能转化。
  - 净利润率：按全部费用与退货后的净值计算。
  - 同行推广手段：观察头部链接依赖的推广方式，判断进入成本。
  - 新品预估 ACOS：用当前竞价与预期转化推算，判断能否承受。
  - 加分项用于同分比较，不替代四项核心。
- 待验证与降级：
  - 各指标阈值需按类目与资金设定。
  - 预估 ACOS 是估算，标注输入。
- 最小证据字段：`niche`, `review_dependency`, `net_margin`, `competitor_promo_methods`, `est_new_product_acos`, `bonus_factors`, `decision`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## ‘大卖看不上、小卖看不见’的切入定位

- 判断要求：新卖家最容易站稳的产品是日销量小到大卖不感兴趣、又偏门到多数新手忽视的细分；几个这样的产品组合起来即可形成可持续收入，而不是一开始追逐大市场。
- 方法要点：
  - 筛选日销个位数、利润率可接受、广告占比低、运营复杂度低的细分。
  - 评估该细分是否会吸引大卖：市场体量越小越不易引来强竞争。
  - 从新手普遍忽视的站点或品类中寻找机会，而不是只盯主流大站。
  - 以产品组合而非单品目标衡量收入，设定每个产品的最小可接受单量。
- 待验证与降级：
  - 素材中的单量与收入数字是经验示例。
  - 小市场的上限意味着增长依赖组合扩张。
- 最小证据字段：`niche`, `daily_units_top_sellers`, `margin`, `ad_share`, `ops_complexity`, `big_seller_presence`, `portfolio_target`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 与工厂的首批小单合作框架

- 判断要求：跨境新品不能保证销量，因此首批多为小批量测款；向工厂提出的合作方式是首批小单以不亏为原则（双方均不盈利），测款失败由卖家承担，成功后的大货订单再形成双赢。
- 方法要点：
  - 明确测款逻辑：首批数量小、目的是验证而非盈利。
  - 谈判首批价格时以工厂不亏为底线，接受略高单价换取小起订。
  - 写明失败风险由卖家承担、成功后大货的价格与利润分配预期。
  - 把该框架作为与新工厂合作的标准说明。
- 待验证与降级：
  - 首批数量与价格让步幅度按品类与是否开模决定。
  - 合同条款需法律复核。
- 最小证据字段：`supplier`, `moq_requested`, `test_batch_qty`, `unit_price_test`, `unit_price_bulk`, `risk_allocation`, `agreement_ref`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## ‘我和头部产品差不多’的认知陷阱

- 判断要求：平台持续把流量分配给表现更好的商品：表现好则建议竞价与实际 CPC 下降。卖家眼中‘与头部同款甚至更好’不等于买家眼中的好；头部已有评价与流量积累，同款后来者没有理由获得同等结果，选品不能照抄头部。
- 方法要点：
  - 用 CPC 与建议竞价的走势作为产品表现的间接信号：持续下降说明表现改善。
  - 把自评的‘质量更好’与买家可感知的差异分开，只有买家能感知并愿意为之选择的差异才算差异。
  - 选品时评估头部积累（评价、流量口）带来的壁垒，避免同款进入。
  - 同类型产品最终只有少数存活，进入前评估自己是否在存活集合里。
- 待验证与降级：
  - CPC 走势受竞争与季节影响，不能单独归因于产品表现。
- 最小证据字段：`asin`, `suggested_bid_series`, `cpc_series`, `cvr`, `head_asin_reviews`, `perceivable_difference`, `decision`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 标品与非标品的流量结构差异及商品定向补位

- 判断要求：标品词少且头部词转化占比高，非标品词多、长尾流量占比高且头部词占比极低；非标与低客单价产品还有较强的关联流量，当买家缺乏明确搜索指向或产品创新难以被搜索时，用商品定向（品类或相似 ASIN）补位。
- 方法要点：
  - 测量头部词转化占比与长尾流量占比，判定产品属于哪一类结构。
  - 标品把资源集中于头部词；接受必要的资金投入，否则不进入该类目。
  - 非标品以词广度与款式多样性为主，利用竞争压力较低的长尾。
  - 搜索指向弱的产品用商品定向投放到相似热销 ASIN 或品类，作为绕过搜索的入口。
- 待验证与降级：
  - 头部词占比数字是经验区间。
  - 商品定向效果需单独衡量。
- 最小证据字段：`asin`, `head_keyword_cvr_share`, `longtail_traffic_share`, `keyword_count`, `product_targeting_asins`, `budget_split`, `window`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 按退货率设定毛利底线

- 判断要求：不含广告费的毛利率没有统一标准，底线由品类退货率决定：低退货标品可接受较低毛利，高退货品类需要明显更高的毛利才能存活。
- 方法要点：
  - 把毛利率与退货率放在同一张表，计算退货损耗后的净贡献。
  - 分品类设定底线：退货率低的标品与退货率高的非标品用不同阈值。
  - 定价前先查自家或同类目的退货率历史，再倒推需要的毛利。
  - 把广告费另列，避免毛利率被广告波动掩盖。
- 待验证与降级：
  - 素材中的百分比阈值是经验值，仅作假设。
  - 退货率需用自家报告，第三方估算只作参考。
- 最小证据字段：`marketplace`, `category`, `gross_margin_ex_ads`, `return_rate`, `return_cost_per_unit`, `net_contribution`, `window`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

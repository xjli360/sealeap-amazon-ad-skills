# Amazon 选品记分卡：核心指标、冷门切入与工厂合作

## 目标

用统一记分卡把候选品拆成核心指标与加分项，结合冷门切入逻辑与退货率毛利底线做出进入或放弃的判断，并给出与工厂的首批合作框架。

## 使用范围

- 优先处理选品与产品开发任务；从专项证据卡选择与当前对象和问题直接相关的主题。
- 集合名称用于维护文件归属，不限制用户要求的交叉验证。其他来源与业务域的证据须分别标注，再按同口径比较。
- 本 Skill 可独立使用，不依赖仓库中的私有语义稿。保留去标识化边界，不恢复原素材身份或逐条映射。

## 适用任务

- 候选品记分与排序
- 细分市场竞争结构判断
- 标品与非标品运营特征预判
- 工厂首批小单谈判准备

## 开始前要拿到

- 候选品的评论依赖度、净利润率、同行推广手段、新品预估 ACOS 输入
- 细分市场头部日销量与大卖参与度的代理数据
- 品类退货率历史与目标毛利
- 候选品的关键词结构（核心词数量、头部词流量占比）
- 供应商起订量、单价与是否开模

缺少字段时明确标为 `UNKNOWN` 或 `NEEDS_EVIDENCE`，不要补造数据。

## 不可妥协的边界

- 本 Skill 来自去标识化语义转译，不保留或推断素材来源身份，也不把素材观点冒充 Amazon 当前政策。
- 产品事实、账户事实和 Amazon 一方报告优先；第三方数据必须标明 Provider、站点、日期、样本和估算口径。
- 不捏造销量、搜索量、成本、合规状态、产品属性、评论、平台通知或执行结果。
- 默认提供诊断或草案。写入前展示对象、旧值、新值、影响、停止线与回退，核对用户已有授权是否覆盖对象、动作与预算；范围已明确授权时继续执行并回读核验，只有未覆盖或扩大的范围才请求批准。
- 平台规则、费率、界面和资格会变化；执行前复核当前官方文档与后台状态。
- 第三方销量、搜索量与转化率均为估算，标注 Provider 与窗口。
- 素材中的毛利百分比与单量区间只作假设。

## 工作流

1. 先用四项核心指标打分，加分项只用于同分比较。
2. 判断细分是否‘大卖看不上、新手看不见’，评估进入后的竞争暴露。
3. 按关键词结构判定标品或非标品，预判流量策略与 SKU 复杂度。
4. 用退货率倒推毛利底线，剔除无法达到的候选。
5. 识别‘与头部同款’陷阱：只有买家可感知的差异才算差异。
6. 与工厂谈首批小单：不亏为底线、失败由卖家承担、成功后大货共赢。

## 专项路由

- **核心指标**：评论依赖度、净利润率、同行推广手段、新品预估 ACOS 四项决定去留，其余为加分项。
- **冷门切入**：日销个位数、利润可接受、广告占比低的细分最易站稳；用产品组合而非单品衡量收入。
- **标品 vs 非标品**：标品词少且头部集中，非标品词多且分散、转化更低、季节波动大、SKU 管理复杂。
- **毛利底线**：退货率越高需要的毛利越高；广告费单列。
- **同款陷阱**：头部已积累评价与流量口，同款后来者没有理由获得同等结果。
- **工厂合作**：首批小单不亏、失败卖家承担、成功大货共赢。

- 候选品记分卡与排序
- 细分竞争结构判断
- 标品或非标品运营预判
- 毛利底线与放弃清单
- 工厂首批合作条款草案

# Amazon 目录与库存运维：表格、变体拆合、断货与购物车：专项证据卡

本文件汇总该组内相近主题的 4 张证据卡，每张卡对应一个去标识化语义单元。以下是分析台账字段，不是可直接传给某个 API 的参数；取数前需映射到实时 schema。只加载当前问题直接相关的卡片，不要无差别执行全部内容。

## 批量表格上传作为链接恢复能力

- 判断要求：用批量表格（flat file）而不是后台逐项上传发布产品，目的是保留在链接异常（如 SKU 与 ASIN 映射变化）时唯一可用的恢复手段。
- 方法要点：
  - 首次发布即用表格上传，并保存每个 SKU 的模板版本与提交记录。
  - 监控 SKU→ASIN 映射：当库存突然变为不可售且映射变化时，用原表格把 SKU 刷回原 ASIN。
  - 后台编辑界面无法处理的映射类问题，只能通过表格提交解决，因此表格是运维资产而非可选步骤。
  - 把表格与产品数据源（属性、图片、关键词）版本化，确保随时可重新提交。
- 待验证与降级：
  - 表格模板字段与处理规则随站点更新，提交前下载当前模板。
  - 刷回 ASIN 前确认没有触发重复创建或合规检查。
- 最小证据字段：`marketplace`, `sku`, `asin_expected`, `asin_current`, `template_version`, `submission_id`, `inventory_status`, `captured_at`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 后台 AI 助手处理变体拆合

- 判断要求：变体拆分与合并可以通过后台内置的 AI 助手用自然语言完成，无需手工编辑或表格；把官方已提供的自动化工具纳入日常操作是效率底线。
- 方法要点：
  - 在后台帮助入口调用 AI 助手，用明确的 ASIN 列表描述拆分或合并需求。
  - 执行前确认对象与影响范围，执行后回读变体关系与库存映射。
  - 对比手工与助手操作的耗时与错误率，决定默认路径。
  - 定期检查官方新增的自动化能力。
- 待验证与降级：
  - AI 助手的可用性、支持的操作与站点以当前后台为准。
  - 自动化操作仍需回读核验，不能视为无风险。
- 最小证据字段：`marketplace`, `asin_list`, `operation`, `tool`, `confirmation_ref`, `readback_result`, `captured_at`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 临近断货时的广告处理

- 判断要求：库存告急时降低广告投入而不是直接关闭；断货本身必然影响权重，唯一解法是让补货速度跑赢消耗，不能靠停售或不可见来规避。
- 方法要点：
  - 按剩余库存与日均单量计算可售天数，把广告预算调到与补货到仓日匹配的消耗节奏。
  - 断货后广告自动停止展示，不产生额外花费，因此无需为省钱而关闭广告结构。
  - 把断货天数、断货前后自然排名与转化记录下来，量化对权重的影响。
  - 补货计划优先于任何‘隐藏链接’类做法。
- 待验证与降级：
  - 权重受损程度与恢复时间是经验判断，需自家数据验证。
  - 库存策略须结合入仓时效与仓容限制。
- 最小证据字段：`marketplace`, `asin`, `inventory_units`, `daily_units`, `days_of_cover`, `inbound_eta`, `ad_budget_daily`, `organic_rank_before`, `organic_rank_after`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 站外低价导致购物车丢失的申诉路径

- 判断要求：先判定触发比价的站外链接与本品是‘同品牌同品’还是‘他人同款’，再选择改价、清除链接或举证差异三条路径之一。
- 方法要点：
  - 确认系统提示的比价来源链接，记录平台、品牌名、图片来源和价格。
  - 若站外链接是自家其他渠道的同品，直接把价格对齐后再申诉。
  - 若是他人冒用品牌或复制链接，先通过对应平台的品牌投诉渠道下架该链接，再向平台申诉恢复购物车。
  - 若是他人以更低价卖‘同款’，申诉材料围绕两点举证：品牌与产品并非同一商品；本品在材质、结构、配件或服务上的差异解释了价格差。
  - 对比双方详情页的材质、功能描述缺口，把对方未声明的规格作为差异化举证点。
- 待验证与降级：
  - 申诉入口、所需材料和处理时限以当前卖家后台帮助文档为准。
  - 差异举证必须基于真实产品事实，不得编造规格。
  - 购物车恢复不等于比价问题消除，需持续监控站外价格。
- 最小证据字段：`marketplace`, `asin`, `buybox_status`, `external_link_ref`, `external_price`, `own_price`, `brand_match`, `evidence_ref`, `case_id`, `captured_at`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

# Amazon 关键词结构：广度、词库、词级投产与否定原则：专项证据卡

本文件汇总该组内相近主题的 7 张证据卡，每张卡对应一个去标识化语义单元。以下是分析台账字段，不是可直接传给某个 API 的参数；取数前需映射到实时 schema。只加载当前问题直接相关的卡片，不要无差别执行全部内容。

## 标品与非标品的关键词广度策略

- 判断要求：非标品流量分散、单词价值低，目标是让足够多的长尾与精准词获得排名，广泛匹配是主要拓词手段；标品关键词少、流量垄断度高，目标是把少数核心词打到靠前位置。
- 方法要点：
  - 先判定产品的流量结构：核心词数量、头部词流量占比、长尾分布。
  - 非标品用广泛匹配持续拓词，评价指标是有排名的关键词数量而非单词排名高度。
  - 标品集中预算于核心词，评价指标是核心词的排名位置与份额。
  - 根据结构选择匹配方式组合，而不是套用统一模板。
- 待验证与降级：
  - 流量垄断度需用第三方或品牌分析数据估算并标注来源。
  - 匹配方式效果随类目变化，需 A/B 验证。
- 最小证据字段：`marketplace`, `asin`, `product_type`, `core_keyword_count`, `head_keyword_traffic_share`, `ranked_keyword_count`, `match_type_mix`, `window`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 一个广告活动放几个词

- 判断要求：词数由控制粒度需求决定：需要单独控制预算与流量的大词单独成活动；预算少、流量小的长尾词可以大量集中在一个活动里。
- 方法要点：
  - 把关键词按流量大小与控制需求分层。
  - 大流量核心词单独建活动，便于独立预算与竞价。
  - 长尾词按主题批量归入同一活动，接受预算共享。
  - 定期把长尾活动中跑出的稳定出单词提升为独立活动。
- 待验证与降级：
  - 词数上限是经验值，需按后台限制与管理能力调整。
- 最小证据字段：`campaign`, `keyword_count`, `keyword_traffic_tier`, `budget_daily`, `control_need`, `promotion_rule`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 预算有限时的关键词收缩

- 判断要求：候选词过多而预算有限时，用三层过滤把词库缩到可承受范围：先用自家广告报告剔除已证明表现差的词，再用搜索量、点击转化率与 CPC 推算 CPA 剔除低量与高 CPA 词，最后剔除推排名所需单量（如 CPR 类指标）超出资金能力的词。
- 方法要点：
  - 先确认候选词来源：竞品反查还是自家广告报告；已跑过广告的词直接按表现分层。
  - 为每个词计算 CPA = CPC / 点击转化率，剔除搜索量过低与 CPA 过高的词。
  - 用第三方推排名所需单量指标估算资金门槛，剔除竞争不起的词。
  - 剩余词按控制需求分配到活动中，并保留被剔除词的清单供后续复用。
- 待验证与降级：
  - 第三方搜索量、转化率与所需单量指标均为估算，需标注 Provider 与时间。
  - 剔除阈值按预算与类目设定，不使用固定值。
- 最小证据字段：`keyword`, `source`, `search_volume_est`, `cvr_est`, `cpc`, `cpa_est`, `rank_units_required_est`, `own_ad_performance`, `decision`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 关键词词库的四维分类

- 判断要求：词库建设分两步：用工具批量收集，再按流量大小、精准性、相关性、词性四个维度分类并合并成板块；分类是词库中最耗时也最关键的环节。
- 方法要点：
  - 收集：多来源采集候选词并去重。
  - 分类维度一：流量大小分层。
  - 分类维度二：精准性（与产品匹配程度）。
  - 分类维度三：相关性（与购买意图的关系）。
  - 分类维度四：词性（品类词、属性词、场景词、品牌词等）。
  - 把多维标签合并为投放板块，作为活动结构的依据。
- 待验证与降级：
  - 分类需人工复核产品相关性，工具输出不等于真实需求。
  - 词库需定期用搜索词报告回流更新。
- 最小证据字段：`keyword`, `search_volume_est`, `precision_tier`, `relevance_tier`, `keyword_type`, `block`, `source`, `updated_at`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 精准词表现变差的原因分层

- 判断要求：一个曾经出单的精准词转差有多种原因：平台层面的季节性转化波动、同行大额折扣或降价改变竞争格局、非标品里某词在自动或广泛中表现好但拿出来单独精准投放后表现差；对应处置分别是随季节调竞价、跟进折扣或减少投放、以及降低该词的竞价与预算。
- 方法要点：
  - 先查该词在全平台或类目的季节性趋势，排除大盘波动。
  - 再查同类竞品是否近期做了大额折扣或降价。
  - 对非标品检查该词在不同匹配方式下的历史表现差异。
  - 按原因选择动作，并记录回退值。
- 待验证与降级：
  - 季节性需用历史数据判断，不凭印象。
  - 竞品折扣信息为前台观测，标注采集时间。
- 最小证据字段：`keyword`, `cvr_series`, `category_seasonality`, `competitor_promo_flags`, `match_type_history`, `bid`, `budget`, `action`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 前置否定的‘不准确 ≠ 不相关’原则

- 判断要求：大量前置精准否定会被系统理解为主动拒绝某类流量，导致广告失去展示、只能靠抬高竞价换流量，CPC 与 ACOS 同时飙升；只可否定完全不相关的词，相关但不精准的词（如同品类的品牌词）不应否定，点击一两次未出单的长尾词也不应急于否定。
- 方法要点：
  - 把候选否定词分为‘完全不相关’与‘相关但不精准’两类，只否定前者。
  - 对竞品反查得到的词库不做前置批量否定，先让广告跑出自家搜索词报告再判断。
  - 对低点击未出单词设置样本门槛，未达门槛不否定。
  - 出现建议竞价远低于实际竞价、且流量枯竭的情形时，检查否定词数量与类型。
- 待验证与降级：
  - 系统学习否定行为的说法是经验推断，用自家数据验证。
  - 否定策略随匹配方式与类目变化。
- 最小证据字段：`campaign`, `negative_keyword_count`, `negative_type`, `relevance_class`, `suggested_bid`, `actual_bid`, `cpc`, `acos`, `impressions_series`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 按词级投产模型选词

- 判断要求：不同关键词天生有不同的竞价与转化率，因此每个词有自己的投产模型；用第三方词级点击转化率（基于品牌分析周数据）、类目均价和目标毛利推算每个词的预估 ACOS 与单笔盈亏，优先投放亏损可承受的词，把大词放到资金与转化允许时再投。
- 方法要点：
  - 从竞品反查得到候选词后，不直接投放，先查每个词的点击转化率与 CPC 估算。
  - 用均价与毛利计算每词预估 ACOS 与每单盈亏。
  - 按可承受亏损排序，小预算先投模型好的词。
  - 自身转化率达不到词级基准时，问题在产品竞争力，不在选词。
- 待验证与降级：
  - 第三方词级转化率是估算（周口径），标注 Provider。
  - 均价与毛利为输入假设，需自家数据替换。
- 最小证据字段：`keyword`, `click_cvr_est`, `cpc_est`, `avg_price`, `gross_margin`, `est_acos`, `est_profit_per_order`, `priority`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

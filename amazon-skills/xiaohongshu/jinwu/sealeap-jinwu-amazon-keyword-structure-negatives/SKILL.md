# Amazon 关键词结构：广度、词库、词级投产与否定原则

## 目标

让关键词结构服从产品的流量结构：非标品追求有排名的词数量、标品追求核心词位置；用词级投产模型与三层过滤在预算内选词；按控制需求决定活动词数；否定只针对完全不相关的流量。

## 使用范围

- 优先处理关键词结构与否定任务；从专项证据卡选择与当前对象和问题直接相关的主题。
- 集合名称用于维护文件归属，不限制用户要求的交叉验证。其他来源与业务域的证据须分别标注，再按同口径比较。
- 本 Skill 可独立使用，不依赖仓库中的私有语义稿。保留去标识化边界，不恢复原素材身份或逐条映射。

## 适用任务

- 关键词广度策略判定
- 词库收集与分类
- 预算内选词与收缩
- 活动词数与结构设计
- 否定词审计与精准词衰退诊断

## 开始前要拿到

- 产品的核心词数量、头部词流量占比与长尾分布
- 候选词的搜索量、点击转化率、CPC 估算及来源
- 自家广告与搜索词报告
- 预算上限与目标毛利
- 现有否定词清单与类型

缺少字段时明确标为 `UNKNOWN` 或 `NEEDS_EVIDENCE`，不要补造数据。

## 不可妥协的边界

- 本 Skill 来自去标识化语义转译，不保留或推断素材来源身份，也不把素材观点冒充 Amazon 当前政策。
- 产品事实、账户事实和 Amazon 一方报告优先；第三方数据必须标明 Provider、站点、日期、样本和估算口径。
- 不捏造销量、搜索量、成本、合规状态、产品属性、评论、平台通知或执行结果。
- 默认提供诊断或草案。写入前展示对象、旧值、新值、影响、停止线与回退，核对用户已有授权是否覆盖对象、动作与预算；范围已明确授权时继续执行并回读核验，只有未覆盖或扩大的范围才请求批准。
- 平台规则、费率、界面和资格会变化；执行前复核当前官方文档与后台状态。
- 第三方词级转化率与搜索量为估算，标注口径。
- 否定词前置批量操作视为高风险动作，需展示影响与回退。

## 工作流

1. 测量流量结构，判定非标品（广度优先）或标品（核心词优先）。
2. 收集候选词并按流量、精准性、相关性、词性四维分类成板块。
3. 为每词计算预估 ACOS 与单笔盈亏，三层过滤到预算可承受的词表。
4. 按控制需求分配活动：大流量核心词单独活动，长尾批量共享预算。
5. 审计否定词：只否定完全不相关的词，相关但不精准的词与低点击长尾词不否。
6. 精准词表现变差时按季节、竞品折扣、匹配方式差异分层处置。

## 专项路由

- **广度策略**：非标品广泛拓词看有排名词数量；标品集中核心词看位置与份额；搜索指向弱的产品用商品定向补位。
- **词库分类**：流量大小、精准性、相关性、词性四维标签合并为投放板块。
- **词级投产**：每词有自己的转化与竞价模型，先投亏损可承受的词。
- **活动词数**：需要精确控制的大词单独成活动，长尾批量集中。
- **否定原则**：大量前置精准否定会让系统屏蔽整类流量，CPC 与 ACOS 同升。
- **精准词衰退**：季节、竞品折扣、匹配方式差异分别对应调竞价、跟进或减投、降竞价降预算。

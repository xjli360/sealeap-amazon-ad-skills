# Amazon 不出单的根因排查：流量、准确性与产品力：专项证据卡

本文件汇总该组内相近主题的 10 张证据卡，每张卡对应一个去标识化语义单元。以下是分析台账字段，不是可直接传给某个 API 的参数；取数前需映射到实时 schema。只加载当前问题直接相关的卡片，不要无差别执行全部内容。

## 转化率低的两分根因

- 判断要求：转化不足只可能来自流量不准（需求匹配错误）或产品力不足（相对同类无优势）；点击率正常而转化低时，先怀疑产品力，而不是继续加广告或无上限加折扣。
- 方法要点：
  - 把点击率作为流量准确性的代理，把转化率作为产品力的代理，分别与同类基准比较。
  - 产品力对照表：外观与功能差异、评论数与评分差距、价格带位置、页面完整度。
  - 在筛选型（多 SKU 快速测试）模式下，广告的作用是引入精准流量以验证产品力，而不是靠广告把弱产品推起来。
  - 折扣是有代价的产品力补丁：若每个测试品都需要靠折扣才转化，说明选品过程失效，应回到选品而非继续让利。
- 待验证与降级：
  - 点击率正常的判断需要同位置、同类目基准，不得用全站平均。
  - 预售或库存未到仓阶段的转化率不能与在售期比较。
  - 折扣梯度测试属于实验，须设停止线与回退。
- 最小证据字段：`marketplace`, `asin`, `placement`, `impressions`, `clicks`, `ctr`, `orders`, `cvr`, `review_count`, `rating`, `price_band`, `window`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 礼品属性产品的转化及格线

- 判断要求：以礼品为主要购买动机的产品通常有较高转化率；若自动与手动广告转化都远低于该类目及格线，问题在产品或定位（只是带有礼品属性而非礼品品），不在广告调法。
- 方法要点：
  - 先确认产品的主要购买动机是否真的是送礼，用搜索词与竞品页面判断。
  - 对照该细分的转化率区间，评估自身转化是否达到可打排名的水平。
  - 远低于及格线时停止调广告，回到产品或定位层面决策：换品或重新定位。
  - 只带部分礼品属性的产品不与专门礼品品同位竞争。
- 待验证与降级：
  - 素材中的转化率区间是经验值，必须用当前类目数据替换。
  - 转化率口径需同位置、同归因窗口。
- 最小证据字段：`marketplace`, `asin`, `category`, `purchase_motive`, `cvr_auto`, `cvr_manual`, `category_cvr_band`, `window`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 新品广告转化与细分市场基准的比较

- 判断要求：判断新品能否盈利，把广告转化率与该细分市场的一方基准（如商机探测器）比较；该基准来自获得前 90% 点击的商品、24 小时归因、仅搜索结果页，属于优秀水平而非平均水平，打排名通常需要高于它一定比例。
- 方法要点：
  - 先核对细分市场是否正确：用精准词对应的细分而非品类大盘。
  - 读取基准的口径：样本范围、归因窗口、流量来源，避免与自家全渠道转化混比。
  - 把自家精准词广告转化率与基准比较，低于基准即缺乏推排名的基础。
  - 低价并不自动带来高转化；同细分更高客单价的商品可能有更高转化，说明问题在产品而非价格。
- 待验证与降级：
  - ‘需高于基准 20–30%’是经验假设，需按类目验证。
  - 基准工具的定义随平台更新，引用前复核当前说明。
- 最小证据字段：`marketplace`, `niche_id`, `benchmark_cvr`, `benchmark_definition`, `own_cvr_exact_match`, `price_vs_niche_median`, `window`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 不出单的三步排查顺序

- 判断要求：产品不出单按固定顺序排查：先看有没有流量（自然或广告点击）；有流量没单再看流量准不准（搜索词报告里的实际搜索词与商品）；流量准仍不转化则是产品竞争力问题，广告无法解决，只能靠让利或换品。
- 方法要点：
  - 第一步核对流量：曝光与点击是否存在及规模。
  - 第二步核对准确性：从搜索词报告看买家实际搜索词和进入路径是否与产品匹配，不准则调整定向。
  - 第三步判定产品力：流量准确却不转化时，测试折扣是否立刻带来转化；若只有深度折扣才出单且亏损，则换品。
  - 前两步属于广告能力，可通过学习改善；第三步不属于广告范畴。
- 待验证与降级：
  - 销量波动本身是正常现象，需先排除周期性再排查。
  - 折扣测试属实验，须设停止线。
- 最小证据字段：`asin`, `impressions`, `clicks`, `search_term_report_ref`, `traffic_relevance`, `cvr`, `discount_test_result`, `window`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 精准词多次点击不成交的处置

- 判断要求：手动精准词已经过筛选却持续点击不成交，说明问题多在链接竞争力（价格合理性、评论基础、产品优势）而不是词；点击量还小时继续观察，点击量已大仍不转化就转向链接与选品复盘。
- 方法要点：
  - 确认词的精准性已经过报告或竞品验证。
  - 设定观察门槛：点击达到足够样本前不下结论。
  - 样本足够仍无成交时，对照竞品检查价格、评论数与评分、卖点差异。
  - 把‘为什么选这个产品’写进选品复盘，避免同类问题重复。
- 待验证与降级：
  - 点击样本门槛按客单价与类目转化率估算。
  - 竞品对照需同站点同时间。
- 最小证据字段：`keyword`, `clicks`, `orders`, `price_vs_competitors`, `review_gap`, `advantage_note`, `decision`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 广告不出单要不要调广告

- 判断要求：不出单是结果，先看广告报告里的实际搜索词是否准确：不准则调整广告；词已经准确却不出单，调整广告没有意义，原因在产品。
- 方法要点：
  - 拉搜索词报告，逐词判断与产品的匹配度。
  - 不准确占比高时调整定向、匹配方式与否定。
  - 准确占比高仍不转化时停止调广告，转向产品与页面。
  - 记录判断依据。
- 待验证与降级：
  - 匹配度判断需人工复核。
  - 样本不足时先积累点击。
- 最小证据字段：`campaign`, `search_terms`, `relevance_share`, `clicks`, `orders`, `decision`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## CPC 远高于同行且无曝光的排查

- 判断要求：CPC 是同行数倍且曝光稀少，要么 Listing 撰写与收录有问题，要么产品表现太差；点击率异常说明页面问题，点击率正常但转化差且流量准确则说明产品问题，答案是换产品。
- 方法要点：
  - 先看点击率是否达到类目正常水平，异常则检查标题、图片、关键词收录。
  - 点击率正常时检查广告流量准确性。
  - 流量准确、点击率正常、转化仍差，判定为产品问题，停止投入。
  - 把高 CPC 视为系统对低表现商品的定价结果，而不是竞价技巧问题。
- 待验证与降级：
  - 同行 CPC 为第三方估算或前台观察。
  - 点击率基准需同位置比较。
- 最小证据字段：`asin`, `cpc`, `peer_cpc_est`, `impressions`, `ctr`, `cvr`, `traffic_relevance`, `decision`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 长期只有广告单的判断

- 判断要求：上架一个月仍全是广告单，说明转化率不足以换来自然流量；可用折扣或降价测试转化提升，但价格降下去容易、回升困难，需缓慢分步；‘一天广告单一天自然单’之类的规律多是小样本体感，样本足够时不会出现。
- 方法要点：
  - 确认单量样本：日单量很小时不对‘规律’下结论。
  - 用折扣测试转化是否随价格弹性改善。
  - 若靶价回升，按小步缓慢回调并观察。
  - 把自然单占比作为产品表现的主指标。
- 待验证与降级：
  - 价格回升难度是经验判断。
  - 样本门槛按日单量设定。
- 最小证据字段：`asin`, `days_since_launch`, `ad_orders`, `organic_orders`, `cvr`, `discount_test`, `price_recovery_steps`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## 点击稀少且无自然单的两层原因

- 判断要求：一个月只有一百多次点击说明竞价与预算过低，数据量不足以判断；长期只有广告单没有自然单说明转化率不达标，表现好的产品哪怕单量小也会有一点自然流量；‘完全没有自然单’需要用报告核实而非体感。
- 方法要点：
  - 先检查竞价与预算是否低到无法积累样本。
  - 核对业务报告中的自然订单，避免体感误判。
  - 样本充足后仍无自然单，判定转化不达标并转向产品。
- 待验证与降级：
  - 点击样本门槛按客单价设定。
- 最小证据字段：`asin`, `clicks_30d`, `bid`, `budget_daily`, `ad_orders`, `organic_orders_report`, `cvr`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

## ‘数据漂亮’的补货陷阱

- 判断要求：只看广告后台的 ACOS 与转化率会误判产品；必须把广告单与总单对照看自然单占比，并把转化率放到细分市场基准里比较。自然单几乎为零且转化率远低于类目平均的产品既没有现在也没有未来，不应补货。
- 方法要点：
  - 把最近周期的广告单与总单并列，计算自然单占比。
  - 用一方或第三方细分市场转化率基准比较自身转化率。
  - 分四种情形决策：有未来（转化优）可接受当前亏损补货；有现在（当前盈利）但无未来可维持不加投；无现在无未来则停止；两者兼备则扩张。
  - 补货决策写明依据的两个对照。
- 待验证与降级：
  - 第三方细分转化率是估算，标注 Provider 与窗口。
  - 自然单占比阈值随类目变化。
- 最小证据字段：`asin`, `ad_orders`, `total_orders`, `organic_share`, `own_cvr`, `niche_cvr_benchmark`, `acos`, `profit_now`, `decision`。
- 输出要求：记录事实、证据来源、站点、时间窗、假设、缺口、风险、停止条件和下一步。

# 日本站长生命周期打法

## 适用判断

在需求全年相对稳定、买家决策慢、品质/功能信任门槛高、评论可持续累积时使用。手册案例为背包，不要将背包的日文关键词或节点直接套入其他品类。

## 消费者与 Listing 前置

优先验证：

- 容量与收纳：口袋、分隔、电脑隔层的实际尺寸；
- 背负舒适：肩带、背部透气和重量；
- 做工品质：缝线、拉链和面料耐用性；
- 防水声明：只在有适用证据时使用；
- 图文一致：内部结构、电脑适配尺寸、颜色和真实装载量。

把“比想象中小”、“拉链损坏”、“内部无分隔”等退货/评论主题转换成 Listing 证据任务，而不是先加竞价。

## 手册中的相对基准

背包案例显示，头部与尾部 ASIN 的品牌推广参与度差距从新品期 `4.3x` 扩大到成熟期 `10.0x`；商品推广花费差距从 `7.3x` 扩大到 `32.8x`。这些数字只用来支持“长期积累与品牌信任重要”的假设，不用来反推当前账户的必要花费。

## 新品期：上架1-3个月

**任务：建立品牌与功能信任，同时降低纯广告依赖。**

手册起始结构（`MANUAL_BASELINE`）：

| 投放类型 | 参考重心 |
|---|---:|
| SP 手动精准/长尾 | 30% |
| SP 自动（紧密匹配） | 15% |
| SP 商品定向 | 15% |
| SB/SBV | 30% |
| SD | 10% |

执行时：

- 从高相关功能长尾词开始，例如手册中的 `通勤 リュック 軽量`、`PC リュック 防水`、`大容量 リュック レディース`；每个词先核对产品事实。
- 用自动广告发现本地表达，将有足够样本的高转化 query 转入手动，不因一个订单就大幅提价。
- 将 SBV 前3秒用于真实内部结构/使用场景，字幕大且日文本地化；不展示未被证据支持的防水、轻量或适配尺寸。
- 在没有品牌资格时，不虚构 SB/SBV；将原预算重新分配到已验证的 SP 长尾词、商品定向和 Listing 改善。

## 成长期：第4-12个月

**任务：用规模与 Listing 转化质量双轮放大。**

手册起始结构（`MANUAL_BASELINE`）：SP手动35%、SP商品定向20%、SP自动5%、SB/SBV30%、SD10%。

- 将新品期已验证的 query 分层，只对高 CVR 且有利润的词测试搜索顶部 placement。
- 将竞品定向分为“强竞品曝光”与“弱竞品转化”，不在同一 Ad Group 混合归因。
- 把 CVR 问题首先路由到尺寸图、收纳结构、电脑隔层适配、做工和评论主题，不用提高竞价掩盖 Listing 问题。
- 更新 SBV 为通勤/通学/旅行等已验证场景，保持一个创意对应一个核心场景。

## 成熟期：第13个月起

**任务：守住品牌/品类入口，激活复购或第二使用场景。**

手册起始结构（`MANUAL_BASELINE`）：SP手动30%、SP商品定向20%、SP自动5%、SB25%、SD20%。

- 为品牌词防守、自然位已稳定词和竞品进攻分别建立实验；不要统一调价。
- 对自然位稳定的词小幅下调竞价时，同时监控总订单与自然订单，验证广告蚯食而非只看 ACOS。
- 只在购买周期证据支持时启动购买再营销。手册的60-180天是背包案例，必须按实际品类修正。
- 将新配色、新功能和礼品场景与旗舰店/品牌推广联动，但不损害变体合规和产品事实。

## 日本站节点补位

- 3-4月入学季：2月底前验证入仓，只在产品适用时使用 `通学 リュック`。
- 7-8月出行季：6月底前验证库存，只突出已证实的轻便、防水或容量属性。
- 11-12月礼品季：10月底前验证包装、库存和礼品搜索意图；不写入未实际提供的礼盒。

# 库存与退货

## 库存情景

比较当前可用的 FBA、AWD 或其它履约方案时，至少输入：预测区间、变体数、旺季峰值、入仓/补货时效、FBA 容量、仓储费、调拨费、缺货损失、滞销清理和现金占用。课程案例不能替代当前费用表。

冗余库存候选按四类处理：跨站销售、促销、移除/清算、保留。每类先算净回收和品牌/退货风险，涉及实际库存操作必须批准。

## 尺码退货 QA

- 同时呈现制造商标签尺码、当地尺码及必要的换算；
- 说明 regular/petite/plus/tall/slim/wide 等真实版型；
- 明确偏大/偏小只能基于可验证测量或稳定反馈；
- 同 product type 与部门保持尺码测量一致；
- 身体测量和商品测量分开；
- 提供测量方法，定期维护品牌尺码表；
- 图片若有模特，披露身高、体型/测量和所穿尺码；
- 颜色、纹理和面料特写必须真实；
- 穿搭配件注明是否随商品包含；
- 使用包容语言与多样形象，但不改变商品事实。

## 退货闭环

按原因编码：尺码/版型、颜色、材料触感、质量、与描述不符、配送损坏、主观偏好。把每类连接到供应商 QA、属性、尺码表、图片、视频、文案或广告人群。一次只改一个主要变量，并比较退货率、CVR 和贡献利润。

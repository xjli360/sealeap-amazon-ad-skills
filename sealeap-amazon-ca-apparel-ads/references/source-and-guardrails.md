## 证据等级

1. `ACCOUNT_ACTUAL`：当前授权账户、同一口径、可追溯报告或 API 数据；
2. `PRODUCT_FACT`：具体 SKU 的包装、说明书、测试、合同或品牌确认；
3. `COURSE_BASELINE`：本 DOCX 的研究与课程建议；
4. `HYPOTHESIS`：从课程推到当前商品的待验证解释；
5. `NEEDS_DATA`：缺少口径、样本、当前资格或账户事实。

结论必须同时标注证据等级、适用 marketplace/ASIN/时间窗和局限。

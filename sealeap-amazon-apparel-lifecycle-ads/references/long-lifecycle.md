# 长生命周期产品 · 广告架构与打法

> 讲师：大鹏（盛阳跨境）+ 楚言（亚马逊广告）
> 适用：西装、连衣裙基础款、紧身衣、打底裤/塑身衣、太阳镜、领带、配饰等销售期 > 3 年的服饰产品

本页百分比均为 2026 年课程画面中的 `COURSE_BASELINE`，用于表达阶段重心，不是当前账户的固定配置。执行前按利润、库存、广告资格与账户数据重算。

长生命周期分两大类，锚点不同：

- **功能基础型** → 锚点：**建立信任**（顾客解决实际问题，不追潮流，款式恒定，追求长期价值，反复确认才下单）
- **功能配饰型** → 锚点：**及时转化 / 超越期望的性价比**（顾客在意主观感受、风格、时尚感）

前置认知：做长生命周期 = 做长跑生意，必须有**高质控且稳定的供应链**，靠持续稳定的品质累积 review 与信任资产。

## A. 功能基础型 · 高客单 / 长决策（案例：Suit 西装）

消费者三个核心疑问：合不合身 / 质量好不好 / 值不值这个价
三大焦虑（来自商机探测器买家评论见解）：**尺码焦虑 · 材质真实性 · 物超所值**

> ⚠️ 性价比 ≠ 低价。性价比是「在同一价格段内，我的产品对比同类型/同面料产品更有优势」。

### 新品期

**核心原则：不盲目拼曝光，用更高的转化率与 ROAS 建立良好基础。**

| 广告类型 | 预算占比 | 具体做法 |
|---|---|---|
| SP 手动关键词 | **50%** | 先避开与头部卖家在**很泛的类目大词**上硬碰硬，先投**相关性属性高的属性词**（试用场景、修身、舞会等），把流量入口扩开 |
| SP 商品投放 | **20%** | 定投**新品榜单/Best Seller 榜单 50 名以后**、与自己直接对标的竞品（找靠前的因 review 数差距大、信任背书缺失）。定投竞品 ASIN 后可在广告位设置商品页面与搜索结果页百分比 |
| SP 自动广告 | **20%** | 围绕 listing 描述做关键词匹配与拓展，找出自己没发现的属性 |
| SB 品牌推广 | **10%** | 用少量素材做测试，主阵地仍在 SP |

**商品投放的讲师假设**：定投竞品 ASIN 后，顾客搜索 `black suit for men` 看到竞品自然位时，你的广告位可能展示在其旁边。讲师认为这种同场出现可能帮助系统形成关联认知；这不是平台承诺或可直接归因的自然流量机制，必须用账户搜索词与自然位变化验证。

**新品期三步动作**：
1. 把属性词分析好（见 keyword-research.md）
2. 按比例分配预算，确保**每个属性的词都吃到预算**
3. 数据跑出后，按属性聚合对比广告报告，找到继续发力的入口

### 成长期

**核心：融入更多 SB 发力，从长尾/属性词往上一层的品类词放大。**

| 广告类型 | 预算占比 | 具体做法 |
|---|---|---|
| SB 品牌推广 | **50%** | 本阶段主阵地 |
| SP 手动关键词 | **30%** | 保住新品期跑出的好词；同时**逐渐往品类词靠**，扩大流量词。匹配方式以**广泛匹配 + 词组匹配**为主（服饰品类精准匹配用得少） |
| SP 商品投放 | **15%** | **强势竞品**：主要用于抢曝光、验证数据；**弱势竞品**：从其详情页拉订单拉转化 |
| SP 自动广告 | **5%** | 好词已被单独拉到手动培养，自动里剩下的优质词变少 |

自动广告若跑出优秀属性词或竞品品牌词，单独拉出来做手动关键词投放（广泛/词组匹配）。

### 成熟期

**核心：以攻为守，重点防御竞品。**

| 广告类型 | 预算占比 | 具体做法 |
|---|---|---|
| SP 手动关键词 | **30%** | 课程拆为防御 10% + 进攻 20%：守「品牌名 + 核心词」，同时继续争夺已验证的品类流量 |
| SP 商品投放 | **10%** | 课程拆为防御 5% + 进攻 5%：守自家详情页，同时从竞品页争夺流量 |
| SP 自动广告 | **0%** | 已完成主要发现与迁移，不再作为成熟期预算主项 |
| SB 品牌推广 | **50%** | 主投品牌词建护城河；落地页可从单一 listing 改为品牌旗舰店，让消费者看到系列产品。订单效率优势须用账户数据验证 |
| SD 展示广告 | **10%** | 两个维度：①复购/二次销售 ②**看了但没买的人群**。大促期间可用再营销告知促销，但先核对当前受众资格 |

## B. 功能基础型 · 低客单 / 短决策（案例：女士打底裤、塑身衣）

**为什么低客单一开始就要做 SB**：
1. **视觉更有说服力**：这类产品在乎塑身、隐形防滑等功能，顾客无法线下试穿，SB 视频格式能短时间快速传递核心卖点，转化能力比图文广告更明显
2. **提高客单价**：低客单复购强，顾客常一次买 3 件/5 件或多种颜色，SB 能同时展示该系列下众多款式和颜色

### 新品期（SP 与 SB 同步快速启动）

| 广告类型 | 预算占比 | 具体做法 |
|---|---|---|
| SP 手动关键词 | **40%** | 投**品类大词，用广泛匹配**，尽可能最大化获取相关流量 |
| SBV / SB 视频 | **30%** | 链接初期 Rating 数量少，靠视频格式快速传递产品信息和卖点 |
| SP 商品投放 | **20%** | 重点关注**上下游能交叉组合搭配的产品**（如打底裤适配长裙/晚礼裙），把关联流量用起来 |
| SP 自动广告 | **10%** | 查漏补缺，积累之前没抓取到的数据 |

**配套：广告预算测算表（大鹏老师提供的公式）**

计算逻辑（黄色区域为填写项）：
- 填入：产品售价、广告订单数、自然订单数（= 业务报告全局订单 − 广告订单）、产品毛利率、当前广告花费
- 填入期望目标值：由目标利润倒推的 TACOS 目标
- 输出：现阶段还有多少钱可以加投到广告活动

举例：产品毛利 40%，仓储/促销等杂费占 10%，期望净利 10% → 综合 TACOS 目标定在 20%。
若算出结果为**负数**，说明为达成目标广告费已花超，需从现有广告类型中优化掉无法转化或匹配过泛的流量。

### 成长期

**重点关注指标：转化率 + ROAS。品牌广告投入达到峰值。**

| 广告类型 | 预算占比 | 具体做法 |
|---|---|---|
| SP 手动关键词 | **50%** | 进一步扩大之前没覆盖的流量入口；品类大词可用广泛匹配配合否定关键词过滤低质量流量 |
| SP 商品投放 | **15%** | 聚焦高转化竞品，优先打自身有优势的弱势品牌/竞品；强势竞品留到下一阶段验证 |
| SP 自动广告 | **0%** | 课程预算表不再保留自动广告主项，已验证词与 ASIN 迁移到手动 |
| SBV / SB 视频 | **35%** | 提高点击与转化，放大系列感和功能表达 |

现象说明：此阶段自然流量积累快，广告订单占总订单比例会**下降**，这是正常的（自然订单占比提高）。

### 成熟期

**重点：放大优质流量，追求优质 CPC 带来优质转化。投放策略从扩张转为保守。**

| 广告类型 | 预算占比 | 具体做法 |
|---|---|---|
| SP 手动关键词（核心词） | **50%** | 此阶段链接信任背书高，核心词效率变好。用**广告位 Bid 加价**向表现最优的位置倾斜；否定不相关流量，并对 CTR、CVR 双低词暂停或降价 |
| SB 品牌推广视频 | **30%** | 从进攻拉量转为品牌防守。课程时点建议在广泛匹配的品牌名前加 `+` 约束搜索词包含品牌名；执行前核对当前美国站控制台是否支持该语法及实际匹配行为 |
| SP 商品推广 | **10%** | 继续打压品类里不如自己的弱势竞品；效果好可用 SD 打到竞品五点下方、购物车下方 |
| SP 自动广告 | **0%** | 不作为成熟期预算主项 |
| SD 再营销 | **10%** | 针对**超过半年以上的老顾客**；结合课程时点的品牌定制促销或优惠券做触达。执行前核对受众资格、费用和折扣成本 |

## C. 功能配饰型 · 季节性（案例：Sunglasses 太阳镜）

产品特征：搜索高峰 **6–7 月**，新品上架后只有 **2–3 个月蓄力窗口**。
目标：短时间内快速抢占流量、抢占坑位、建立市场认知。

### 新品期（激进抢量）

| 广告类型 | 预算占比 | 具体做法 |
|---|---|---|
| SP 手动关键词 | **40%** | 以核心大词为根，但不只投大词精准；打开核心词拓展入口，并加入适配场景词与节日礼物词 |
| SP 商品投放 | **30%** | 锁定与自身有明确款式、审美或价格带优势的竞品 ASIN，验证人群与关联语境 |
| SP 自动广告 | **20%** | 挖掘之前没发现的长尾词，观察属性匹配效果 |
| SB / SBV | **10%** | 短平快测试多个卖点、场景图或视频素材，不拉长素材验证周期 |

### 成长期（用品牌广告拉品牌价值）

| 广告类型 | 预算占比 | 具体做法 |
|---|---|---|
| SP 手动关键词 | **40%** | 继续加大核心词投放，抢更靠前位置（核心词本身 + 其拓展词） |
| SB / SBV | **35%** | 课程建议可测试 SBV + VCPM；素材场景若符合受众，可提升订单效率。执行前核对当前计费与资格 |
| SP 商品投放（强弱竞品合计） | **15%** | 强势竞品用于抢曝光，弱势竞品用于抢转化；15% 是总占比，不是各 15% |
| SP 自动广告 | **10%** | 季节性品类会有之前没人搜、到时间点才有人搜的新词，自动广告能及时返回 |

### 成熟期（全面放量拿结果，利润最大化）

| 广告类型 | 预算占比 |
|---|---|
| SP 手动关键词 | **40%**（其中要把成长期测出的优质视频放进 **SPV** 投放） |
| SD 展示广告 | **25%** |
| SP 商品推广 | **20%** |
| SB 品牌推广 | **15%** |

理由：SD 与 SB 相比 SP 展示效果更丰富。

**SPV（商品推广视频）新功能说明**（楚言）：
- 在现有 SP 广告活动中直接添加产品视频即可，无需新建
- 可上传 **1–5 个、不短于 7 秒**的视频
- 每个视频可展现产品在不同消费者关注功能点上的表现
- 适合成熟期 + 季节性款式做全面放量的阶段

以上 SPV 规格为 2026 年课程时点信息；执行前核对当前美国站控制台、素材资格与计费方式。

## D. 功能配饰型 · 无季节性（案例：Necktie 领带）

产品特征：全年需求稳定，课程口播提到 **7 月及 Q4** 有搜索高峰，课件对 Q4 具体月份的摘要略有差异。实际排期以目标年份的 ABA/搜索趋势验证。可借关联品（如西装 Suit）的搜索趋势带动订单。

### 新品期（精准高效突围）

核心词广告价格贵，但新品期又需要订单带排名，因此：

| 广告类型 | 预算占比 | 具体做法 |
|---|---|---|
| SP 手动关键词 | **50%** | **聚焦长尾关键词**，可用词组/精准：包含材质、颜色、piece 数量（6 piece / 4 piece）、彩色/印花/纯色/混色搭配等具体属性 |
| SP 商品投放（关联场景） | **35%** | 投放上下游能组合搭配的产品：西装、领带夹等。逻辑同线下购物——买衬衣时营业员会顺手拿一条领带 |
| SP 自动广告 | **10%** | 抓取之前没看到的关联产品 ASIN 与关键词 |
| SB 品牌推广 | **5%** | 测试素材，为成长期发力做准备 |

### 成长期（SP + SB 双驱动）

| 广告类型 | 预算占比 | 具体做法 |
|---|---|---|
| SP 手动关键词 | **40%** | 已抓到的好词争取更靠前位置，继续保持高效长尾入口 |
| SP 商品投放 | **20%** | 关注关联品投放，以及竞品详情页间的比较流量 |
| SP 自动广告 | **10%** | 继续找拓展词与关联 ASIN |
| SB 品牌推广 | **20%** | 全色系呈现并可引导至旗舰店；让领带、领带夹、领结形成组合购买 |
| SD 展示广告 | **10%** | 触达买过关联品但未购买领带的人群；执行前核对当前受众资格 |

### 成熟期（以利润换护城河，主做防守）

| 广告类型 | 预算占比 | 具体做法 |
|---|---|---|
| SP 关键词 | **30%** | 核心词卡住位置 + 更多**品牌词覆盖**，防止被竞品截流（搜自己品牌名看到的却是竞品广告位＝火烧到自家后院）；保持高长尾词转化 |
| SP 商品投放 | **15%** | 锁定关联品牌；SKU 多时，用其他 SKU 定投到自己主推 SKU 下方，做**自家流量闭环** |
| SD 展示广告 | **15%** | 定向已购顾客推送其他色系；人群调研触达**买过西装的用户** |
| SB 品牌推广合集 | **40%** | 维持品牌词曝光，同时展示多个系列产品 |

**品牌推广合集（Brand Collection）新功能说明**（楚言）：
- 是过去「品牌推广商品集」的升级
- **手动合集**：课程画面明确为卖家选择 **3–10 个 ASIN**，消费者可左右滑动查看
- **自动合集**：系统根据 listing 与消费者需求动态选品，可排除不想投放的低利润商品；课程未明确自动合集的 10 个上限
- 从今年 **3 月起**在全球各站点陆续开放，美国站已可见

以上品牌推广合集描述为 2026 年课程时点能力；执行前核对当前美国站是否开放、展示数量与资格。

## E. 否词、预算护栏与复盘闭环

### 否词与迁移

- 课程未给统一的“点击 N 次无单”或固定花费阈值，不要自造。按账户转化延迟、利润和最低样本设定停止条件。
- 低客单成长期可用“品类大词广泛匹配 + 否定关键词”过滤低质量流量；成熟期否定不相关流量，并对 CTR、CVR 双低词暂停或降价。
- 自动广告跑出的高 CTR、高 CVR 属性词或竞品词，迁移到独立手动活动；迁移与否词不要在同一实验卡中同时执行。

### TACOS 预算护栏

课程示例用毛利、仓储/促销等费用与目标净利倒推 TACOS：毛利 40% - 其他费用 10% - 目标净利 10% = TACOS 20%。这只是计算示例，不是服饰统一目标。若剩余可投金额为负，优先清理无转化或过泛流量。

### 周期复盘

1. 下载搜索词报告与搜索词展示份额报告；
2. 按材质、颜色、款式、场景等属性聚合曝光、点击、订单和花费，不对 1–2 次点击的偶发词下结论；
3. 横向比较属性效率，把双高词从自动迁移到手动；
4. 按 ABA 流量层级拆活动，确保不同层级都能获得预算；
5. 再结合 CVR、ROAS、placement 与竞品强弱调整下一轮唯一主变量。

Listing、尺码、视觉、购物篮分析、复购与品牌定制促销的运营动作见 [operations.md](operations.md)。

# 季节性产品 · 广告架构与打法

> 讲师：二喵（Moses）+ 楚言（亚马逊广告）
> 适用：泳装、女裙、外套、手套、毛衣、靴子、角色扮演服等有明显高峰低谷、旺季窗口集中 2–4 个月的服饰产品

本页百分比均为 2026 年课程画面中的 `COURSE_BASELINE`。只有能够从课件闭合到 100% 的表格才列出完整占比；来源有歧义时只保留方向，不擅自补数。

## 0. 开场警示 — 一个真实踩坑案例

二喵接手一款**女士简约连衣裙**（不夸张、不小众、很百搭）。因为觉得"看起来通用"，就默认沿用标品/通用产品的打法：

> 新品期先把流量入口全铺开 → SP 自动 + SP 手动 + SB + SBV + SD 能开的都开 → 再慢慢筛选优化。

**结果**：竞价和预算一路高升，花费上来了、首页位置也拿到了，但销量很难上去，甚至断崖式下降。把出单词单独拉出来重新投放也没用。

**根本原因**：
- 服饰不是靠客观参数成交的产品，卖家以为"通用"，但买家不会这么理解
- **主身份还没收住，就先把入口铺满，非常容易乱**
- 提竞价加预算后，系统确实把链接推到了更多位置，但**新拿到的位置触达的人群不一定适合这个款式**。很多人即使不会买，也会因为图片、模特、喜欢的颜色先点进来逛一逛 → 表面点击变多、流量放大，实际**真正适合这条裙子的人群占比被冲淡了**

**第二年的调整**：
1. 复盘去年真正稳定有转化的词，归类出是哪一类词、哪一类场景、哪一类人群
   - ⚠️ 判断标准：**不能因为一个词偶尔出过一单就当好词**（点击少时偶然性太大）。课程举例可观察到“上百次点击”后是否仍能稳定出单，但这只是 `COURSE_EXAMPLE`，账户阈值应由利润、CVR 与统计样本决定
2. 修正人群理解。原来只会说"适合 30 岁左右女性"——太泛，30 岁左右的身材偏好、审美方式、生活方式、出行场景差别都太大
3. 把跑出的风格词、场景词、感受词整理成词包，反过来重做 listing：**不是写得更多更满，而是写得更准**
4. 广告围绕**一个主推款**做清楚分工：
   - SP Broad（广泛）→ 负责拓量，看系统把产品带到哪些风格和场景
   - SP Phrase（词组）→ 承接已验证的高效方向
   - SP Exact（精准）→ 守核心成交词
   - Product Targeting（商品投放）→ 吃竞品页流量

**课程经验**：修正广告方向后，流量可能波动，新的风格、场景和人群方向也需要新的样本验证。曝光和流量可能下降；只有相关性、转化和利润同步改善，才能判断流量质量变好。

## 1. 季节性产品的两种细分类型

| | 纯季节性 | 周期性 |
|---|---|---|
| 代表 | Dress 女裙、Swimwear 泳装 | Costume Outfit 角色扮演服、Pants |
| 驱动因素 | **季节趋势 + 流行趋势双重驱动** | **节庆 / 促销节点驱动** |
| 趋势特征 | 通常前两次销售高峰后，因款式风格快速更迭而快速衰退 | 经历多个销售高峰，第二个旺季往往才是最高峰 |
| 产品性质 | 受潮流影响大 | 经典不易过时的基础款，对潮流敏感度低 |
| 复购逻辑 | 一次交易为主，可做多色多款 | 体验好会在**下一个周期复购** |
| 消费者三问 | ①穿上合身显身材吗 ②款式颜色好看吗 ③实物和图片一致吗 | ①价格划不划算 ②质量能撑多久 ③功能体验好吗 |
| 买的是什么 | "到了季节，我该换条漂亮的新裙子" | "到了这个时间点，我需要一个**直接能解决问题的方案**" |
| **广告锚点** | **抓住旺季窗口，用视觉驱动转化** | **跨周期积累优势 + 促销节点集中转化** |

**周期性产品的额外要求**（以万圣节女巫扮演服为例）：
1. **吃时间节点**：用户本来就有需求，但会等到节点、觉得价格合适才集中下单 → 性价比很重要
2. **质量和耐用性决定能否撑过多个销售周期**：这一轮积累的评价、信任、评分会影响下一轮消费者的信心
3. **买回来到底好不好用**：穿脱麻不麻烦、好不好搭配。**能给一整套搭配方案更容易促进下单**

## 2. 季节性产品的生命周期怎么划分

⚠️ 季节性产品的三个阶段**不按上架天数固定划分**，且两个细分类型不能套同一张日历：

| 细分类型 | 新品期 | 成长期 | 成熟期 |
|---|---|---|---|
| **纯季节型（Dress）** | 第一个旺季到来之前：收敛主身份、场景词与素材 | 第一个旺季窗口：承接并放大已验证方向 | 第二个旺季及以后：复用评价、排名、成交词和素材，同时准备收尾 |
| **周期型（Costume Outfit）** | 第一轮促销周期：在节点前完成布局，并以首轮转化建立基础 | 第二轮促销周期：复用第一轮资产集中转化 | 第三轮及以后：防守、再营销与跨周期复购 |

课程把上述阶段分别解释为标签建立、强化、稳定；这是 `COURSE_MODEL`，不是 Amazon 后台字段。真正的阶段判定要同时看是否经历并沉淀上一轮旺季、实际销售曲线、搜索趋势、库存与账户表现。

## 3. 纯季节性（Dress）三阶段打法

### 新品期 — 让系统和用户看懂"这件衣服穿在身上是什么感觉"

不是先强推流量，而是先验证两件事：①实际搜索词与商品入口是否趋向目标方向 ②用户看到后能不能建立**上身想象**。

| 广告类型 | 预算占比 | 做法 |
|---|---|---|
| **SP 手动关键词** | **35%** | 新品期的地基。**核心不是一上来就投最大的词**，而是先把季节性核心词与长尾词收进去 |
| **SP 商品投放** | **20%** | 用相关商品页测试搭配关系和场景语境，以实际点击、转化和搜索词/定向报告验证假设 |
| **SP 自动广告** | **15%** | 充当**验证器**：跑出的流量接近目标风格与场景，可作为方向证据；持续泛化时复核 Listing、素材、定向与否词，不做单一归因 |
| **SBV / SPV 视频** | **30%** | 季节性服饰新品期**视频尽早上线特别关键**，因为它天生依赖"穿上是什么感觉"。视频任务不是拍成大片，而是**真实、多角度、干净整洁**，把版型、材质、上身效果、动态感表现清楚 |

> ⚠️ 预算比例是**阶段性重心参考**，不是固定模板。判断依据三条：①当前阶段最重要的任务是什么 ②产品当前最缺什么（曝光/点击/转化）③该节点的竞争强度与利润空间是否支撑。

### 成长期 — 放大已验证的风格与场景

> `SOURCE_CONFLICT`：源画面分别列出“手动关键词 35% + 品牌推广 40% + 商品投放 15% + 礼品相关手动词组 10% + 自动 5%”，合计 105%。课程未明确礼品词 10% 是否包含在手动关键词 35% 内，因此本阶段只保留角色与方向，不复原成 100% 生产预算表。

| 广告类型 | 做法 |
|---|---|
| SP 关键词 | 主任务是**放大新品期跑出的好词**（高点击高转化），逐步往精准与核心词组收；源画面另列礼品相关词组 10%，因归属不清，只能作为待核对的辅助子组，不能直接额外加到总预算 |
| SP 商品投放 | 更主动：**找强势竞品抢曝光，找弱势竞品抢转化**（服饰用户本来就会对比款式、风格、价格、评价） |
| SP 自动广告 | 占比降低，不再是验证主工具，更多是测试有没有新入口 |
| SB 品牌广告 | 比重拉高，用更多**真实穿搭视频**刺激点击和转化 |

⚠️ **礼品流量只是辅助**。节日过去之后一定要把它收回来，**产品主身份绝不能被弱化**。

### 成熟期 — 吃透优势并准备收尾

| 广告类型 | 预算占比 | 做法 |
|---|---|---|
| SP 手动关键词 | **30%** | 词已更聚焦，守住已验证的高转化词，慢慢缩减低效词。**否词是持续动作**；课程建议可每周集中看一次搜索词报告，实际频率按花费速度、归因窗口和样本量调整。品牌词与核心风格词要守住，别被竞品截留 |
| SB 品牌广告 | **40%** | 消费者更看视觉新鲜感与内容质量。成熟期**不要重复用前面同一套素材**，可换模特、换场景、更新视频素材 |
| SP 商品投放 | **15%** | 偏防守：一部分投自己店铺其他同类 ASIN 做内部流量防守，另一部分继续投弱势竞品接转化机会 |
| SD 展示广告 | **15%** | 承接前面看过但还没买的人，追加购买机会 |

## 4. 周期性（Costume Outfit）三阶段打法

以万圣节女巫扮演服为例。

### 新品期 — 立住"节庆任务身份"

两件核心事：①让实际搜索词与商品入口围绕“万圣节女巫扮演服”收敛 ②建立基础转化，为后面几轮节点积累证据。

| 广告类型 | 预算占比 | 做法 |
|---|---|---|
| **SP 手动关键词** | **40%** | 收住**主身份词**（女巫扮演服、女士女巫扮演服等），让广告流量与产品实际用途保持一致，而不是扩散到普通黑色裙子 |
| **SP 商品投放** | **30%** | 一部分投同类女巫扮演服、节庆服饰的头部商品；另一部分测试**万圣节装饰、糖果袋、派对道具**等强关联商品，以定向报告验证任务场景相关性 |
| **SB 品牌广告** | **25%** | 不只展示品牌，也告诉用户我有不同尺码、不同搭配、适合家庭亲子多人拍照场景，降低第一次尝试的门槛 |
| **SP 自动广告** | **5%** | 测试实际匹配入口。流量围绕“女巫/万圣节”可作为主身份收敛证据；持续偏向“普通黑色裙子”则复核 Listing、定向与否词 |

### 成长期 — 放大已验证的购买理由

| 广告类型 | 预算占比 | 做法 |
|---|---|---|
| SP 关键词 | **35%** | 把第一轮验证过的高转化词往核心词组收；**到了真实促销节点把预算往上提抢首页位置** |
| SP 商品投放 | **20%** | 继续盯高转化竞品和评价相对弱的同类竞品，把用户在别人那里犹豫的流量拦下来 |
| SP 自动广告 | **5%** | 持续看有没有新表达、新细分入口 |
| SB / SBV | **30%** | 放大这套方案的**高性价比**和**一站式解决方案**属性——整套效果合不合场景、穿脱方不方便、帽子裙子摆件到不到位 |
| SD 展示广告 | **10%** | 做**预热**：提前触达已浏览过类似节庆的人，为节庆当天集中蓄水转化 |

### ⚠️ 淡季为什么不要完全停广告

很多人认为女巫扮演服的高峰就在万圣节前几天，淡季干脆停掉。但这类周期性产品**淡季更适合"清投/保温"而非彻底断掉**，三个原因：

1. **淡季不是完全没单**：有些活动、cosplay 场合仍有需求。单量不大，但价值在于**持续告诉系统"我就是这个女巫扮演服，我还在这里"**
2. **淡季竞争更低，点击成本通常更低**：可用低成本维护身份、积累下一轮先发优势
3. **这类产品适合测试提早占位**：临近万圣节时竞争与 CPC 可能上升，停投后重启也需要重新积累样本；是否持续保温须由淡季需求、利润和库存验证，不假定存在平台处罚

**淡季具体做法**：①保持核心词不断投（竞价低一点、预算少一点也要持续）②保持 SB / SBV 存在，持续放大身份。

### 成熟期 — 防守与复用

普通裙子到成熟期是慢慢接受衰退，但女巫裙对应的是**反复出现的任务场景**，成败取决于前几轮积累的评价、位置与客户能否让下一轮卖得更轻松。

| 广告类型 | 预算占比 | 做法 |
|---|---|---|
| SP 手动关键词 | **30%** | 守住核心词与品牌词，同时盯新来的竞品做进攻 |
| SP 商品投放 | **15%** | 详情页防守：一方面投自己其他商品防止流量被劫走，另一方面继续投弱势竞品巩固份额 |
| SB / SBV | **25%** | 重点从拉新转到**老客回购、品牌黏性、跨周期复购**；用新素材重新连接老客户 |
| SD 展示广告 | **30%** | 成熟期最关键：把前几轮积累的人群重新激活——买过的推新款，看过竞品但没买的再触达 |

## 5. 站外联动（广告加速器）

服饰天生依赖视觉、销售窗口又集中，只做站内不够。站外的价值在于：**先帮你把视觉方向测出来，把上身信任感建立起来，再让站内接住这批已被打动的人。**

**三个目标**：
1. **种草**：找真人穿搭、达人上身视频，比卖家自己的图文更容易让用户带入"穿上去的样子"。**不用找特别大的网红**，只要账号垂直、是当地人、愿意做穿搭即可，粉丝不用太多。AI 工具也可生成素材，但**尽量保持真实场景感**
2. **测素材**：测你的产品适合哪种场景、哪种表达更打动人。有自有站外账号能更快拿到反馈，也可铺更多素人账号
3. **建立信任感**：消费者最怕"图片好看、穿身上很丑"。站外真实上身效果能带来所见即所得的信任感

**站内外联动的时间线**：
- **旺季前** → 用站外把视觉方向先验证出来
- **旺季中** → 由站内承接并放大
- **旺季后** → 用再营销把这波流量价值拉长

**六个具体动作**：
1. **选合适渠道**：强视觉导向产品（Dress、Swimwear）先看 **TikTok、Instagram**；多款式有氛围感的可看 **Pinterest**（课程现场分享了 Pinterest 上一个 8 秒展示 4 条裙子的高氛围感视频广告案例）
2. **内容聚焦上身效果**：站外最重要的不是讲一堆卖点，而是回答"我穿上去到底是什么样子"。真人穿搭视频、多体型模特上身图更高效
3. **小批量测试**：先小批量测颜色、款式、场景，看哪种互动更好，再反过来用到站内
4. **站内站外表达必须统一**：站外说的是"适合度假的轻松裙子"，用户点进站内却看到"性感约会裙"的文案视频 → 严重冲突，用户会犹豫
5. **给合作达人专属折扣码**：用于衡量站外真实贡献
6. **旺季后不要立刻断掉**：用 SD 或 DSP 定向前面看过、买过的人推多色多款，把销售周期拉长

## 6. 季节性产品的三个运营要点

### 要点 1：准备工作必须跑在流量前面

**旺季倒推时间表**：
| 时间 | 动作 |
|---|---|
| 提前 **4 个月** | 完成上架与页面优化 |
| 提前 **2 个月** | 开始广告投放、关键词积累、标签建立 |
| 提前 **1 个月** | 确认 FBA 库存与调仓节奏 |

（官方针对具体节日的通用建议：至少提前 **2–3 个月**；二喵补充：**最少也要提前 1 个月**做场景词收录动作。）

**如何解释课程中的时间差异**：

- 首次上新的 Dress 案例强调最早可在旺季前约 4 个月进入“上架 + 页面 + 广告准备/启动”；老品下一季通常可用已沉淀的词与素材，在旺季前约 2 个月重启广告积累。
- 广告启动前必须已有可售库存与 Buy Box。上表“提前 1 个月确认 FBA”是最终库存与调仓复核节点，不代表此前可以无库存投放。
- 具体年份的节庆日期、FBA 截止时间、补货周期和在途风险优先于课程倒排模板。

**善用站内外促销放大转化**：站内提前看准 Prime Day、黑五等节点；站外配合社媒预热、达人内容、专属优惠码，把促销信息先放出去，等流量真正进来时接的是已经被提醒过、被种草过的一批人。

**别浪费上一轮的数据资产**：老品尤其是周期性产品，把上一轮跑出的高转化关键词、表现好的素材整理好，用于下一轮启动。

### 要点 2：素材决定转化率上限

这也是为什么头部 ASIN 的 SB 参与度从新品期到成熟期持续走高——他们在持续投入视觉内容。

1. **上架前准备好多场景多角度素材**，尤其是视频。不需要拍得非常大片，关键是**真实可信**。用短视频分别展示上身效果，**页面视频位尽量放满**
2. **持续更新素材**：这类产品看过一遍后吸引力会递减。到第二个旺季前如果还用同一套素材很难再吸引到人。可换搭配、换场景、换模特，用新的视觉表达延缓审美疲劳（现在用 AI 也很容易实现）

### 要点 3：把控库存节奏

1. **旺季前不要断货**：参考上一轮旺季的数据（广告转化率、关键词表现）预估本轮单量；有条件时配合**海外仓或 AWD**，降低旺季断货风险，让补货更灵活
2. **旺季尾声主动调库存**：不要等卖不动了再想办法。像泳装这种强季节性需求，旺季过后需求明显下滑，要及时配合促销折扣清货，不要让长期仓储费侵蚀利润

预算上调不能机械跟随竞价翻倍：先看 CVR、盈亏平衡 ACOS、自然排名和库存承接能力。旺季结构可同时保留盈利型与投资型活动，但组合结果至少要满足预先定义的盈亏与库存护栏。

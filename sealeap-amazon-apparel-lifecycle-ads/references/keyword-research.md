# 服饰非标品找词方法论

> 主要来自大鹏（盛阳跨境）的实操演示，二喵（Moses）补充

## 0. 为什么服饰的找词逻辑与标品不同

课程数据集提供了一个观察：在**热门搜索词**里看某个大词下点击份额最高的前三名 ASIN——这些已经是强势 ASIN，但其在某一个具体词上的**转化份额仍然有限**。这是课程样本的描述性结果，不是当前美国站或具体账户的保证。

**推论**：推非标品时必须**把流量入口打开、做到多元化**，并保证每个属性层级的词都能吃到预算。如果只抓几个具体词打精准匹配，订单不会稳。

---

## 1. 方法一：商机探测器「订单效率」算法

亚马逊后台 → 商机探测器 → 找到与自己最相关的细分市场 → 搜索词选项卡。

平台会给出该细分市场对应的 **20 个关键词**，每个词都提供：
- 过去 360 天搜索量
- 过去 360 天搜索转化率

**关键操作**（平台没有直接给出订单数）：

```
该词过去 360 天贡献订单数 ≈ 过去360天搜索量 × 过去360天搜索转化率
```

注：商机探测器这部分只统计**搜索结果页面**的数据。

**双维度排序法**：
1. 按**搜索量**降序，取前 10 个词，标注一种颜色（如绿色）
2. 按**计算出的订单数**降序，取前 10 个词，标注一种颜色
3. 观察三类词：
   - **双绿词**：搜索量高 + 订单效率贡献也高 → **前期重点埋词对象**
   - **搜索量高但订单效率低**：顾客搜索前会用这类词，但最终影响购买决策的往往不是它，而是某些长尾词或带属性的词
   - **搜索量不高但订单效率进入前十**：往往比"标红"的高搜索低效率词更值得投

**筛选标准**：该词属性与自己产品**相关性高** + 搜索量与订单效率贡献都不错 → 前期重点埋词与投放。

**顺带**：进入细分市场后先看**买家评论见解**，重点关注好评点提及率与差评点提及率最高的原因，在上架前就做改进升级。

## 2. 方法二：热门搜索词（ABA）流量层级分层

品牌分析 → 热门搜索词，搜索类目核心大词（如 `mens suit`）。

- 每个词条都有对应的**搜索频率排名**（ABA 排名），**值越小代表搜索量越大**
- 服饰品类的特点：搜完一个核心词后会给出以它为中心的大量拓展词，每个层级都有很多词——10 万名以内的、10–11 万的、11 万、12 万、13 万的……**下降坡度比较缓**

**分层建广告活动的规则**：

> 假设投了一个颜色词，ABA 排名 9.3 万；又找到一个属性词（如 2-piece），ABA 排名 3–4 万。
> **这两个词不要放到同一个广告活动里。**

原因：不同流量层级的词放在一起，低层级的词吃不到预算。分开建活动才能**确保每个流量层级的词都吃到相应预算**。

这也是为什么 SP 手动关键词那 50% 的预算**不是主要花在其中某几个词上**——非标品词非常多，只有把流量入口抓得更多，订单才会稳定。

## 3. 方法三：按「属性」聚合分析搜索词报告（最重要）

**问题**：推服饰这类偏非标的产品，广告报告里很多数据都是一两次点击，有的出单有的没出单，**流量非常分散**。单独看某一个具体词根本无法有效分析，因为都是偶然数据。

**正确做法**：

1. 先把不同属性做好归类（材质：亚麻 / 雪纺 / 纯棉；数量：2-piece / 3-piece；颜色：black；风格：修身 / 性感；场景：舞会 / 晚宴）
2. 下载**搜索词报告**或**搜索词展示份额报告**
3. 在报告里**单独搜索某一个属性**，把所有包含该属性的关键词累计起来看：曝光、点击、订单、花费
4. 属性与属性之间横向对比 → 得出该侧重往哪些属性加码

判断标准：这个属性对比其他属性，**是否仍是现阶段能拿到有效结果的属性**。是 → 继续在该属性词上扩大投入。

**新品期的三步动作总结**：
1. 把属性词分析好
2. 按比例分配预算，确保**每个属性的词都吃到预算**
3. 数据跑出后，按属性聚合对比广告报告，找到继续发力的入口，扩大排名和订单

## 4. 匹配方式选择

| 匹配方式 | 服饰品类中的角色 |
|---|---|
| **广泛匹配** | 主力。用于拓量、看系统把产品带到哪些风格和场景 |
| **词组匹配** | 主力。承接已验证的高效方向 |
| **精准匹配** | 用于已验证、高相关、需要守排名或防御的词；不是服饰全阶段默认主力。Necktie 新品可用词组/精准聚焦高相关长尾，Sunglasses 成长期可把双高词迁入精准/广泛，成熟期常用于守核心成交词与品牌词 |
| **广泛匹配 + 「+」限制符** | 课程时点的成熟期品牌防御方法：在自己品牌名前加 `+`，用于约束顾客搜索词包含品牌名。执行前必须核对当前美国站控制台是否仍支持该语法及其实际匹配行为 |

## 5. 自动广告的定位（随阶段变化）

| 阶段 | 自动广告的作用 |
|---|---|
| 新品期 | ①围绕 listing 做关键词匹配与拓展，找出没发现的属性 ②**充当验证器**：跑出的词若接近你想表达的风格与场景 → 方向对了；越跑越泛 → listing/素材没讲清楚 ③补充没想到的搜索词 |
| 成长期 | 预算占比逐渐减少。好词已被单独拉到手动培养，自动里剩下的优质词变少。跑出优秀属性词或竞品品牌词时，单独拉出来做手动投放（广泛/词组） |
| 成熟期 | 占比最低，主要看有没有新入口 |
| 季节性产品特例 | 季节性品类会有"之前没人搜、到时间点才有人搜"的新词，自动广告能及时返回，价值仍在 |

⚠️ 诊断信号：**成长期自动广告还在大量跑但表现不好** → 要么主身份没建立好，要么已有信号但没做收敛（该否的词没否）。

## 6. 关键词的三层分类（短生命周期 · 高信任壁垒型专用）

新品期做精准收敛时围绕三类词建身份：

1. **主身份词** — 你的产品到底是什么
2. **主需求词** — 买家真正在意的点（如内衣：舒适、支撑度、无痕、尺码准确）
3. **主成功变量词** — 你真正有竞争力的独特卖点

聚焦**高意向、低竞争的长尾词**，不要一上来把词打得太散。

---

## 7. 词的成长路径（长生命周期）

```
新品期：避开泛类目大词 → 投相关性高的属性词/长尾词（把入口扩开）
   ↓
成长期：保住已验证的好词 → 逐渐往上一层的品类词放大（补足流量入口缺失）
   ↓
成熟期：核心词效率变好（链接信任背书已高）→ 主投核心词 + 品牌词防御，减少低效流量
```

---

## 8. 否词是持续动作

- 课程讲师建议可**每周集中看一次**搜索词报告；这是复盘节奏示例，不是平台硬频率，需按花费速度、归因窗口和样本量调整
- 季节性产品的**礼品/节日流量只是辅助**，节日过去后一定要收回，避免弱化主身份
- 否掉：明显不合适的流量、无法有效转化的、匹配过于泛的流量

---

## 9. 一个反直觉的组合：关键词投放 + 商品投放同时测

短生命周期与季节性产品前期，**不要只投关键词**。

课程假设：服饰买家很多时候被打动的是**一个已经成型的商品语境**——竞品页可能承载场景、价格带、人群和购买理由，因此商品投放在前期**可能**比关键词投放更快跑出有效信号。必须通过同窗口、同护栏的账户实验验证，不能视作平台因果结论。

正确做法：两者一起跑，**看谁先跑出对的信号、谁先成为主词**。
